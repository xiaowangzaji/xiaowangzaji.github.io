1. GPT 自回归生成

1.1 核心思想

GPT 是自回归模型：每次只预测下一个 token，然后把预测的 token 加入输入，继续预测下一个。

def generate(model, tokenizer, prompt, max_length=100):
    input_ids = tokenizer.encode(prompt)
    
    for _ in range(max_length):
        # 获取模型输出
        logits = model(torch.tensor([input_ids]))
        
        # 取最后一个 token 的 logits
        next_token_logits = logits[0, -1, :]
        
        # 采样（可调温度）
        temperature = 0.7
        next_token_logits = next_token_logits / temperature
        probs = F.softmax(next_token_logits, dim=-1)
        next_token = torch.multinomial(probs, num_samples=1)
        
        # 终止条件
        if next_token == tokenizer.eos_token_id:
            break
            
        input_ids.append(next_token.item())
    
    return tokenizer.decode(input_ids)

1.2 训练目标

# GPT 训练目标：最大化似然
def gpt_loss(model, input_ids, labels):
    logits = model(input_ids)
    
    # 只计算下一个 token 的 loss
    shift_logits = logits[..., :-1, :].contiguous()
    shift_labels = input_ids[..., 1:].contiguous()
    
    loss = F.cross_entropy(
        shift_logits.view(-1, shift_logits.size(-1)),
        shift_labels.view(-1)
    )
    return loss

2. 推理优化技术

2.1 KV Cache

自回归生成中，之前计算的 Key 和 Value 可以缓存复用：

# 原始推理（无缓存）
def forward_no_cache(model, input_ids):
    # 每个 token 都要重新计算所有历史
    return model(input_ids)

# 优化推理（KV Cache）
def forward_with_cache(model, input_ids, past_key_values):
    # 只计算新 token 的注意力
    output, kv_cache = model(input_ids, use_cache=True, past_key_values=past_key_values)
    return output, kv_cache

效果：推理时间从 O(n²) 降到 O(n)

2.3 投机解码 (Speculative Decoding)

用小模型生成候选，大模型验证：

def speculative_decode(draft_model, target_model, input_ids, k=4):
    # 小模型快速生成 k 个 token
    draft_tokens = draft_model.generate(input_ids, max_new_tokens=k)
    
    # 大模型批量验证
    logits = target_model(draft_tokens)
    
    # 接受或拒绝
    accepted = []
    for i, (draft_tok, logit) in enumerate(zip(draft_tokens, logits)):
        if torch.rand() < F.softmax(logit, dim=-1)[draft_tok]:
            accepted.append(draft_tok)
    
    return accepted

2.4 连续批处理 (Continuous Batching)

多个请求共享计算：

请求1: [A B C]        →    请求1: [A B C D]
请求2: [D E]       →    请求2: [D E F]
请求3: [F G H I]      →    请求3: [F G H I J]

5. 总结

GPT 推理优化核心：

  1. KV Cache - 避免重复计算
  2. 量化 - 减少显存和计算
  3. 批处理 - 提高 GPU 利用率
  4. 投机解码 - 加速生成

选择合适的部署方案，可以显著提升推理性能。
