一、数据结构与算法的基本概念

数据结构是计算机存储、组织数据的方式，算法是解决特定问题的一系列步骤。两者相辅相成，高效的数据结构能提升算法性能，优秀的算法往往依赖于合适的数据结构。

程序 = 数据结构 + 算法

二、数据结构分类

线性结构

  • 数组：连续内存存储，支持随机访问。
  • 链表：通过指针链接节点，插入删除高效。
  • 栈：后进先出（LIFO），适用于函数调用等场景。
  • 队列：先进先出（FIFO），适用于任务调度。

非线性结构

  • 树：层次结构，如二叉树、B树，用于搜索和排序。
  • 图：由顶点和边组成，适用于网络建模、路径规划。

三、算法核心要素

时间复杂度

描述算法执行时间随输入规模的增长趋势。常见表示法：

  • O(1)O(1)O(1)：常数时间。
  • O(log⁡n)O(\log n)O(logn)：对数时间，如二分查找。
  • O(n)O(n)O(n)：线性时间，如遍历数组。

空间复杂度

衡量算法运行时所需的额外存储空间（不包括输入数据本身）。

情况空间复杂度示例
原地算法O(1)O(1)O(1)冒泡排序、双指针反转
辅助数组O(n)O(n)O(n)归并排序的临时数组
递归调用栈O(log⁡n)O(\log n)O(logn) ~ O(n)O(n)O(n)快速排序 O(log⁡n)O(\log n)O(logn)，最坏递归 O(n)O(n)O(n)

空间换时间：缓存/哈希表将 O(n)O(n)O(n) 查找降到 O(1)O(1)O(1)，但消耗 O(n)O(n)O(n) 空间。

五、栈和队列详细

5.1 栈（Stack）

特点：后进先出（LIFO），仅允许在栈顶操作。

// 顺序栈
#define MAX_SIZE 100
typedef struct {
    int data[MAX_SIZE];
    int top;  // 栈顶指针，-1 表示空
} Stack;

void push(Stack* s, int val) {
    if (s->top < MAX_SIZE - 1) s->data[++s->top] = val;
}

int pop(Stack* s) {
    if (s->top >= 0) return s->data[s->top--];
    return -1;  // 空栈
}

应用场景：

场景说明
函数调用调用栈保存局部变量和返回地址
括号匹配左括号入栈，右括号匹配出栈
表达式求值中缀→后缀转换，后缀表达式求值
浏览器前进/后退两个栈分别维护历史
DFS 实现递归本质就是系统栈
撤销操作（Undo）操作历史入栈，Ctrl+Z 出栈

5.2 队列（Queue）

特点：先进先出（FIFO），一端入队，一端出队。

// 循环队列（避免假溢出）
#define MAX_SIZE 100
typedef struct {
    int data[MAX_SIZE];
    int front;  // 队头
    int rear;   // 队尾
    int count;  // 元素个数
} Queue;

void enqueue(Queue* q, int val) {
    if (q->count < MAX_SIZE) {
        q->data[q->rear] = val;
        q->rear = (q->rear + 1) % MAX_SIZE;
        q->count++;
    }
}

int dequeue(Queue* q) {
    if (q->count > 0) {
        int val = q->data[q->front];
        q->front = (q->front + 1) % MAX_SIZE;
        q->count--;
        return val;
    }
    return -1;
}

应用场景：

场景说明
BFS层次遍历、最短路径
任务调度操作系统进程调度、消息队列
缓冲区生产者-消费者模型
打印队列多个打印任务排队

5.3 单调栈

特点：栈内元素单调递增/递减，用于寻找最近的更大/更小元素。

# 寻找每个元素右边第一个更大的元素
def nextGreaterElement(nums):
    stack = []  # 单调递减栈，存索引
    result = [-1] * len(nums)
    for i in range(len(nums)):
        while stack and nums[i] > nums[stack[-1]]:
            result[stack.pop()] = nums[i]
        stack.append(i)
    return result
# 时间复杂度: O(n)，每个元素最多入栈出栈各一次

6.2 二叉树遍历

typedef struct TreeNode {
    int val;
    struct TreeNode* left;
    struct TreeNode* right;
} TreeNode;

// 前序遍历（根 → 左 → 右）：8 3 1 6 4 7 10 14 13
void preorder(TreeNode* root) {
    if (!root) return;
    printf("%d ", root->val);
    preorder(root->left);
    preorder(root->right);
}

// 中序遍历（左 → 根 → 右）：1 3 4 6 7 8 10 13 14
void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    printf("%d ", root->val);
    inorder(root->right);
}

// 后序遍历（左 → 右 → 根）：1 4 7 6 3 13 14 10 8
void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->val);
}

// 层序遍历（BFS）：8 3 10 1 6 14 4 7 13
void levelOrder(TreeNode* root) {
    if (!root) return;
    Queue q; initQueue(&q);
    enqueue(&q, root);
    while (!isEmpty(&q)) {
        TreeNode* node = dequeue(&q);
        printf("%d ", node->val);
        if (node->left) enqueue(&q, node->left);
        if (node->right) enqueue(&q, node->right);
    }
}

重要结论：

  • 前序 + 中序 → 唯一确定一棵二叉树
  • 后序 + 中序 → 唯一确定一棵二叉树
  • 前序 + 后序 → ❌ 不能唯一确定（无法区分左右子树）

6.3 二叉搜索树（BST）

性质：

  • 左子树所有节点值 < 根节点值
  • 右子树所有节点值 > 根节点值
  • 左右子树也分别为 BST
// BST 查找
TreeNode* searchBST(TreeNode* root, int val) {
    if (!root || root->val == val) return root;
    if (val < root->val) return searchBST(root->left, val);
    return searchBST(root->right, val);
}

// BST 插入
TreeNode* insertBST(TreeNode* root, int val) {
    if (!root) {
        TreeNode* node = (TreeNode*)malloc(sizeof(TreeNode));
        node->val = val;
        node->left = node->right = NULL;
        return node;
    }
    if (val < root->val) root->left = insertBST(root->left, val);
    else root->right = insertBST(root->right, val);
    return root;
}

6.5 红黑树概述

红黑树的五条性质：

  1. 每个节点是红色或黑色
  2. 根节点是黑色
  3. 叶子节点（NIL）是黑色
  4. 红色节点的子节点必须是黑色（无连续红节点）
  5. 从任一节点到其所有叶子节点的路径上，黑色节点数量相同

特点：

  • 最长路径不超过最短路径的 2 倍（近似平衡）
  • 插入/删除最多 3 次旋转，比 AVL 更高效
  • Java HashMap（桶链表 ≥ 8 转红黑树）、TreeMap、C++ std::map 底层都用红黑树

6.6 B 树与 B+ 树

B 树（B-Tree）：

  • 多路平衡搜索树，节点可存多个键和多棵子树
  • 所有叶子在同一层
  • 每个节点同时存储 key 和 data

B+ 树：

  • 只有叶子节点存储 data，非叶子节点只存 key 作为索引
  • 叶子节点之间用链表连接
  • 更适合范围查询和磁盘存储
对比B 树B+ 树
数据存储所有节点仅叶子节点
范围查询需中序遍历叶子链表直接扫
单键查询可能中途找到必须到叶子
磁盘 I/O较多较少（扇出更大）
数据库应用少InnoDB 默认索引结构

七、排序算法详细

7.1 算法实现与特点

# 1. 冒泡排序 - O(n²)
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped: break  # 优化：已有序提前退出

# 2. 选择排序 - O(n²)
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]: min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]

# 3. 插入排序 - O(n²)
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key

# 4. 希尔排序 - O(n log n) ~ O(n²)
def shell_sort(arr):
    n = len(arr)
    gap = n // 2
    while gap > 0:
        for i in range(gap, n):
            temp = arr[i]
            j = i
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        gap //= 2

# 5. 归并排序 - O(n log n)
def merge_sort(arr):
    if len(arr) <= 1: return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

# 6. 快速排序 - O(n log n)
def quick_sort(arr):
    if len(arr) <= 1: return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 7. 堆排序 - O(n log n)
def heap_sort(arr):
    n = len(arr)
    # 建堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    # 逐个提取
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)

def heapify(arr, n, i):
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2
    if left < n and arr[left] > arr[largest]: largest = left
    if right < n and arr[right] > arr[largest]: largest = right
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

八、查找算法

8.1 顺序查找

int sequential_search(int arr[], int n, int key) {
    for (int i = 0; i < n; i++)
        if (arr[i] == key) return i;
    return -1;
}
// 时间复杂度: O(n)，适用于无序表

8.2 二分查找

int binary_search(int arr[], int n, int key) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;  // 防溢出
        if (arr[mid] == key) return mid;
        else if (arr[mid] < key) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
// 时间复杂度: O(log n)，要求有序

8.3 分块查找（索引顺序查找）

将数据分成若干块，块内无序、块间有序。先二分查找确定块，再块内顺序查找。

块1: [22, 12, 13, 8]   max=22
块2: [33, 42, 28, 38]   max=42
块3: [55, 48, 62, 58]   max=62
块4: [77, 82, 91, 88]   max=91

查找 48 → 索引表找到块3 → 块3内顺序查找

8.4 哈希表（Hash Table）

核心思想：通过哈希函数将 key 映射到数组位置，实现 O(1)O(1)O(1) 查找。

# Python 字典底层就是哈希表
d = {'name': 'Alice', 'age': 25}
d['name']  # O(1) 查找

9.2 图的遍历

BFS（广度优先搜索）：

from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    while queue:
        vertex = queue.popleft()
        print(vertex)
        for neighbor in graph[vertex]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
# 时间复杂度: O(V + E)，空间: O(V)
# 应用: 最短路径（无权图）、层次遍历

DFS（深度优先搜索）：

def dfs(graph, start, visited=None):
    if visited is None: visited = set()
    visited.add(start)
    print(start)
    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
# 时间复杂度: O(V + E)，空间: O(V)（递归栈）
# 应用: 连通性检测、拓扑排序、环检测

9.3 最短路径算法

Dijkstra 算法（单源最短路径，非负权）：

import heapq

def dijkstra(graph, start, n):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]  # (距离, 顶点)
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue
        for v, weight in graph[u]:
            if dist[u] + weight < dist[v]:
                dist[v] = dist[u] + weight
                heapq.heappush(pq, (dist[v], v))
    return dist
# 时间复杂度: O((V+E) log V)，空间: O(V+E)
# 不能处理负权边！

Floyd-Warshall 算法（多源最短路径，可处理负权但不能有负环）：

def floyd(graph, n):
    dist = [[float('inf')] * n for _ in range(n)]
    for i in range(n): dist[i][i] = 0
    for u, v, w in graph: dist[u][v] = w

    for k in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
    return dist
# 时间复杂度: O(V³)，空间: O(V²)
# 核心思想: 动态规划，逐步考虑中间顶点

9.4 最小生成树

Prim 算法（加点法，适合稠密图）：

def prim(graph, start, n):
    visited = [False] * n
    min_dist = [float('inf')] * n
    min_dist[start] = 0
    mst_weight = 0

    for _ in range(n):
        # 选最近的未访问顶点
        u = -1
        for i in range(n):
            if not visited[i] and (u == -1 or min_dist[i] < min_dist[u]):
                u = i
        visited[u] = True
        mst_weight += min_dist[u]
        for v, w in graph[u]:
            if not visited[v] and w < min_dist[v]:
                min_dist[v] = w
    return mst_weight
# 时间复杂度: O(V²) / O((V+E) log V)（优先队列优化）

Kruskal 算法（加边法，适合稀疏图）：

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx != ry:
            self.parent[rx] = ry
            return True
        return False

def kruskal(edges, n):
    edges.sort(key=lambda x: x[2])  # 按权值排序
    uf = UnionFind(n)
    mst_weight = 0
    count = 0
    for u, v, w in edges:
        if uf.union(u, v):
            mst_weight += w
            count += 1
            if count == n - 1: break
    return mst_weight
# 时间复杂度: O(E log E)，空间: O(V + E)

十、递归与分治思想

10.1 递归

三要素：

  1. 终止条件：防止无限递归
  2. 递归关系：将问题缩小为子问题
  3. 返回值：子问题的结果如何合并
# 斐波那契数列（递归）
def fib(n):
    if n <= 1: return n
    return fib(n-1) + fib(n-2)
# 问题: 大量重复计算 → 时间复杂度 O(2^n)

# 优化: 记忆化
memo = {}
def fib_memo(n):
    if n <= 1: return n
    if n not in memo:
        memo[n] = fib_memo(n-1) + fib_memo(n-2)
    return memo[n]
# 时间复杂度: O(n)

10.2 分治法

步骤：分解 → 解决 → 合并

# 归并排序 = 分治的经典应用
def merge_sort(arr):
    if len(arr) <= 1: return arr       # 终止条件
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])        # 分解 + 解决
    right = merge_sort(arr[mid:])       # 分解 + 解决
    return merge(left, right)           # 合并

十一、动态规划基础

  2. 状态转移方程

11.2 0-1 背包问题

# dp[i][w] = 前 i 件物品，容量为 w 时的最大价值
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [0] * (capacity + 1)
    for i in range(n):
        for w in range(capacity, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[capacity]
# 时间复杂度: O(n × W)，空间: O(W)（一维优化）
# 注意: 一维数组必须倒序遍历，否则同一物品会被重复使用

11.3 完全背包问题

# 与 0-1 背包唯一区别: 正序遍历
def unbounded_knapsack(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for i in range(len(weights)):
        for w in range(weights[i], capacity + 1):  # 正序
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[capacity]

11.4 最长公共子序列（LCS）

def lcs(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
# 时间复杂度: O(m × n)，空间: O(m × n)
# 示例: lcs("abcde", "ace") → 3 ("ace")

十二、贪心算法

12.1 核心思想

每一步都选择当前最优解，希望得到全局最优。前提：问题具有贪心选择性质和最优子结构。

# 活动选择问题（经典贪心）
def activity_selection(activities):
    """activities = [(start, end), ...]"""
    activities.sort(key=lambda x: x[1])  # 按结束时间排序
    selected = [activities[0]]
    last_end = activities[0][1]
    for start, end in activities[1:]:
        if start >= last_end:
            selected.append((start, end))
            last_end = end
    return selected
# 贪心策略: 总是选择结束时间最早且与已选活动不冲突的活动

12.2 贪心 vs 动态规划

维度贪心动态规划
选择策略当前最优，不回溯枚举所有选择，取最优
子问题只做一次选择考虑所有可能的选择
正确性需证明贪心选择性质自动保证最优
效率通常更快可能较慢
适用特殊结构问题一般优化问题
