Python 环境搭建

概述

在开始 Python 开发之前，需要搭建好开发环境。本章节将介绍 Python 的安装、环境配置和虚拟环境管理。

一、安装 Python

1.1 Windows 安装

  1. 下载 Python
  • 访问 Python 官网
  • 下载最新版本的 Python 3.x
  1. 安装步骤
  • 勾选 "Add Python to PATH"
  • 选择 "Customize installation"
  • 勾选所有可选功能
  • 选择安装路径
  1. 验证安装
python --version
pip --version

1.2 Linux 安装

# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# CentOS/RHEL
sudo yum install python3 python3-pip

# 验证
python3 --version
pip3 --version

1.3 macOS 安装

# 使用 Homebrew
brew install python3

# 验证
python3 --version
pip3 --version

1.4 使用 Anaconda

# 下载 Anaconda
wget https://repo.anaconda.com/archive/Anaconda3-2023.07-Linux-x86_64.sh

# 安装
bash Anaconda3-2023.07-Linux-x86_64.sh

二、环境配置

2.1 pip 使用

# 升级 pip
python -m pip install --upgrade pip

# 安装包
pip install requests
pip install numpy pandas

# 卸载包
pip uninstall package_name

# 查看已安装的包
pip list

# 导出依赖
pip freeze > requirements.txt

# 从文件安装
pip install -r requirements.txt

2.2 镜像源配置

# 临时使用
pip install package -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久配置
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

常用镜像源：

  • 清华：https://pypi.tuna.tsinghua.edu.cn/simple
  • 阿里：https://mirrors.aliyun.com/pypi/simple
  • 腾讯：https://mirrors.cloud.tencent.com/pypi/simple

2.3 环境变量

# Windows 添加到 PATH
# C:\Python311\
# C:\Python311\Scripts\

# Linux 添加到 .bashrc
export PATH="/usr/local/python/bin:$PATH"

三、虚拟环境

3.1 venv（推荐）

# 创建虚拟环境
python -m venv myenv

# 激活（Windows）
myenv\Scripts\activate

# 激活（Linux/Mac）
source myenv/bin/activate

# 退出
deactivate

3.2 virtualenv

# 安装
pip install virtualenv

# 创建
virtualenv myenv

# 激活
source myenv/bin/activate

3.3 conda 环境

# 创建环境
conda create -n myenv python=3.11

# 激活
conda activate myenv

# 退出
conda deactivate

# 列出环境
conda env list

# 删除环境
conda env remove -n myenv

3.4 Poetry

# 安装
pip install poetry

# 创建项目
poetry new myproject

# 安装依赖
poetry install

# 添加依赖
poetry add requests

四、开发工具配置

4.1 VS Code 配置

  1. 安装 Python 扩展
  2. 选择解释器：Ctrl + Shift + P → Python: Select Interpreter
  3. 配置调试
{
    "python.linting.enabled": true,
    "python.formatting.provider": "black",
    "python.analysis.typeCheckingMode": "basic"
}

4.2 PyCharm 配置

  1. 下载并安装 PyCharm
  2. 创建项目时选择 Python 解释器
  3. 配置虚拟环境

4.3 Jupyter Notebook

# 安装
pip install jupyter notebook

# 启动
jupyter notebook

# 常用命令
# %timeit - 计时
# %run - 运行脚本
# %%writefile - 写入文件

五、常用开发环境

5.1 数据科学环境

pip install numpy pandas matplotlib scikit-learn jupyter

5.2 Web 开发环境

pip install django flask fastapi uvicorn

5.3 机器学习环境

pip install tensorflow pytorch scikit-learn jupyter

六、常见问题

6.1 pip 安装失败

# 清除缓存
pip cache purge

# 使用 --no-cache-dir
pip install --no-cache-dir package

6.2 权限错误

# Linux/macOS 使用 --user
pip install --user package

# 或使用虚拟环境

6.3 版本冲突

# 使用虚拟环境隔离
python -m venv env1
python -m venv env2
