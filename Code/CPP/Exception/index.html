C++异常处理

2026-04-06

异常基础

try-catch 语法

try {
    // 可能抛出异常的代码
    int age = -1;
    if (age < 0) {
        throw "年龄不能为负数";
    }
} catch (const char* e) {
    cout << "捕获异常: " << e << endl;
} catch (int e) {
    cout << "捕获整数异常: " << e << endl;
} catch (...) {
    cout << "捕获所有异常" << endl;
}

抛出异常

// 抛出整数
throw 10;

// 抛出字符串
throw "错误信息";

// 抛出异常对象
throw runtime_error("运行时错误");

异常类型

标准异常

#include <stdexcept>

try {
    // 越界访问
    vector<int> v(5);
    v.at(10) = 0;  // 抛出 out_of_range
} catch (const out_of_range& e) {
    cout << e.what() << endl;
}

try {
    // 无效参数
    throw invalid_argument("无效参数");
} catch (const invalid_argument& e) {
    cout << e.what() << endl;
}

常用标准异常

异常类型说明
std::exception所有异常基类
std::runtime_error运行时错误
std::logic_error逻辑错误
std::out_of_range越界
std::invalid_argument无效参数
std::bad_alloc内存分配失败

异常规范

// 传统方式
void func() throw(std::runtime_error);  // 可能抛出 runtime_error

// C++11 noexcept
void safeFunc() noexcept;  // 不抛出异常
void mayThrow();            // 可能抛出异常

// 在函数声明中指定
template<typename T>
void process(T& item) noexcept(std::is_trivially_destructible<T>::value) {}

异常与析构函数

class Resource {
public:
    ~Resource() noexcept {
        // 不应抛出异常
        // 如果析构函数可能抛出异常，需使用 std::terminate
    }
};

// 最佳实践：析构函数永远不要抛出异常
class Good {
public:
    ~Good() noexcept {}
};
