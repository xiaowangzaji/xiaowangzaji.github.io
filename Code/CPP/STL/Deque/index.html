deque 简介

deque（双端队列）是两端都可以高效插入和删除的连续内存容器。

基本用法

头文件

#include <deque>

创建与初始化

deque<int> d1;              // 空双端队列
deque<int> d2(5);           // 5个元素，值为0
deque<int> d3(5, 10);       // 5个元素，值为10
deque<int> d4 = {1, 2, 3};  // 初始化列表

常用操作

deque<int> d;

// 两端操作
d.push_front(1);     // 头部插入 O(1)
d.push_back(2);     // 尾部插入 O(1)
d.emplace_front(0); // C++11，原地构造
d.emplace_back(3);
d.pop_front();      // 头部删除 O(1)
d.pop_back();      // 尾部删除 O(1)

// 访问
d[0];              // 下标访问（不检查越界）
d.at(0);           // 下标访问（检查越界）
d.front();         // 首元素
d.back();          // 尾元素

// 大小
d.size();          // 元素个数
d.empty();         // 是否为空

// 修改
d.insert(d.begin() + 2, 5);  // 在中间插入（较慢）
d.erase(d.begin());          // 删除
d.clear();                  // 清空

遍历

for (int num : d) {
    cout << num << " ";
}

for (size_t i = 0; i < d.size(); i++) {
    cout << d[i] << " ";
}

实现原理

底层结构

deque 采用分段连续内存的策略，由一个中控器管理多个缓冲区：

template <class T>
class deque {
private:
    // 中控器：存储指向各缓冲区的指针
    T** map_;              // 指针数组
    size_t map_size_;      // 中控器大小
    
    size_t start_cur_;     // 起始缓冲区的起始位置
    size_t finish_cur_;    // 结束缓冲区的当前位置
    
    // 为了快速访问首尾
    iterator start_;       // 指向第一个元素
    iterator finish_;      // 指向最后一个元素的下一个
};

内存布局

[map_ 指针数组]
  ↓
[buffer0] [buffer1] [buffer2] [buffer3] ...
     ↓          ↓         ↓         ↓
   元素       元素      元素       元素

每个缓冲区可以存储多个元素（通常 512 字节或 8 个元素）。

中控器结构

中控器是一个动态数组，存储指向各个缓冲区的指针：

// 中控器示意图
[ptr0] [ptr1] [ptr2] [ptr3] [ptr4] [ptr5]
   ↓      ↓      ↓      ↓      ↓      ↓
  块0    块1    块2    块3    块4    块5

当需要扩展时：

  1. 在中控器两端分配新的缓冲区
  2. 更新指针数组

访问原理

下标访问：

  1. 计算元素在整个 deque 中的索引
  2. 计算该元素在哪个缓冲区
  3. 计算在该缓冲区中的偏移量
  4. 直接访问
// 伪代码
reference operator[](size_t n) {
    size_t buf_index = n / buffer_size;
    size_t offset = n % buffer_size;
    return map_[buf_index][offset];
}

两端操作原理

push_front：

  • 如果起始缓冲区还有空间，直接插入
  • 否则分配新缓冲区

push_back：

  • 如果结束缓冲区还有空间，直接插入
  • 否则分配新缓冲区

时间复杂度

操作时间复杂度说明
push_frontO(1)
push_backO(1)
pop_frontO(1)
pop_backO(1)
operator[]O(1)
insertO(n)中间插入需移动元素
eraseO(n)

迭代器实现

deque 的迭代器需要处理跨缓冲区的情况：

template <class T>
struct iterator {
    T** cur;      // 指向当前元素的指针
    T** first;   // 指向当前缓冲区的起始
    T** last;    // 指向当前缓冲区的末尾
    T** node;    // 指向当前缓冲区在中控器中的位置
};

特点

  • 双端高效：两端操作都是 O(1)
  • 连续访问：支持下标访问 O(1)
  • 内存分段：逻辑上连续，物理上分段
  • 无扩容：不需要像 vector 那样整体扩容
