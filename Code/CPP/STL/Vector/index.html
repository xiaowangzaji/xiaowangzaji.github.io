vector 简介

vector 是 C++ 标准模板库（STL）中的动态数组容器，可以自动扩展容量，无需手动管理内存。

基本用法

头文件

#include <vector>

创建与初始化

vector<int> v1;              // 空向量
vector<int> v2(5);           // 5个元素，值为0
vector<int> v3(5, 10);       // 5个元素，值为10
vector<int> v4 = {1, 2, 3};  // 初始化列表
vector<int> v5(v4);          // 拷贝构造

常用操作

vector<int> v;

// 添加元素
v.push_back(1);      // 尾部添加
v.emplace_back(2);  // C++11，原地构造，更高效

// 访问元素
v[0];               // 下标访问（不检查越界）
v.at(1);            // 下标访问（检查越界）
v.front();          // 首元素
v.back();           // 尾元素

// 大小操作
v.size();           // 元素个数
v.empty();          // 是否为空
v.capacity();       // 当前容量

// 修改
v.pop_back();       // 删除尾部元素
v.insert(v.begin(), 0);  // 插入
v.erase(v.begin());     // 删除
v.clear();         // 清空
v.reserve(100);    // 预留容量
v.resize(10);      // 调整大小

遍历

// 下标遍历
for (size_t i = 0; i < v.size(); i++) {
    cout << v[i] << " ";
}

// 迭代器遍历
for (auto it = v.begin(); it != v.end(); it++) {
    cout << *it << " ";
}

// 范围 for 循环（C++11）
for (int num : v) {
    cout << num << " ";
}

特性

  • 动态扩容：容量不足时自动扩容（通常翻倍）
  • 连续内存：支持随机访问，下标访问 O(1)
  • 尾部操作高效：push_back O(1) 均摊
  • 中间操作低效：insert/erase O(n)

实现原理

底层结构

vector 底层是一个动态数组，包含三个核心指针：

template <typename T>
class vector {
private:
    T* start_;      // 指向数据起始位置
    T* finish_;     // 指向当前元素末尾（不含）
    T* end_of_storage_;  // 指向存储空间末尾（不含）
};

内存布局

[start_] [ элемент 0 ][ элемент 1 ][ ... ][ элемент n-1 ] [finish_] [未使用...end_of_storage_]

扩容机制

当 finish_ == end_of_storage_ 时，需要扩容：

  1. 申请新空间：通常为原容量的 2 倍
  2. 拷贝元素：将旧空间元素拷贝到新空间
  3. 释放旧空间：释放原内存
  4. 更新指针：更新 start_、finish_、end_of_storage_
// 伪代码
void push_back(const T& value) {
    if (finish_ == end_of_storage_) {
        size_t new_capacity = capacity() * 2;
        T* new_start = new T[new_capacity];
        // 拷贝构造
        for (size_t i = 0; i < size(); i++) {
            new_start[i] = start_[i];
        }
        delete[] start_;
        start_ = new_start;
        finish_ = start_ + old_size;
        end_of_storage_ = start_ + new_capacity;
    }
    new (finish_) T(value);  // placement new
    finish_++;
}

时间复杂度

操作时间复杂度说明
push_backO(1) 均摊偶尔扩容时 O(n)
pop_backO(1)
operator[]O(1)直接计算偏移量
insertO(n)需要移动元素
eraseO(n)需要移动元素
sizeO(1)
reserveO(n)扩容时需要拷贝

迭代器失效

以下操作会导致迭代器失效：

  • push_back 扩容后
  • insert/erase 后
  • clear/resize 等
