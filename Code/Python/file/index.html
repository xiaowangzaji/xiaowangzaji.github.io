Python 文件操作

概述

文件操作是 Python 中的重要技能，用于读取配置文件、处理数据文件、生成报告等场景。本章将介绍文件的基本读写、路径处理和常用技巧。

一、文件打开与关闭

1.1 基本语法

file = open(文件名, 模式)
# 操作文件
file.close()

代码说明：使用 open() 函数打开文件，返回文件对象。

模式描述
r只读模式（默认）
w写入模式（覆盖）
a追加模式
rb二进制只读
wb二进制写入
ab二进制追加

1.2 with 语句（推荐）

with open('file.txt', 'r', encoding='utf-8') as file:
    content = file.read()
# 文件自动关闭

提示

使用 with 语句可以确保文件正确关闭，即使发生异常也能正确释放资源。

二、文件读取

2.1 读取全部内容

with open('test.txt', 'r', encoding='utf-8') as f:
    content = f.read()
    print(content)

代码说明：使用 read() 一次性读取整个文件内容。

2.2 读取单行

with open('test.txt', 'r', encoding='utf-8') as f:
    line = f.readline()
    print(line)

2.3 读取所有行

with open('test.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()
    for line in lines:
        print(line.strip())

2.4 遍历文件对象

with open('test.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line.strip())

三、文件写入

3.1 写入字符串

with open('output.txt', 'w', encoding='utf-8') as f:
    f.write('Hello, World!\n')
    f.write('第二行内容')

3.2 写入多行

lines = ['第一行\n', '第二行\n', '第三行\n']

with open('output.txt', 'w', encoding='utf-8') as f:
    f.writelines(lines)

3.3 追加内容

with open('log.txt', 'a', encoding='utf-8') as f:
    f.write('新的日志内容\n')

四、文件指针操作

4.1 获取当前位置

with open('test.txt', 'r') as f:
    f.read(5)  # 读取前5个字符
    position = f.tell()
    print(f"当前指针位置: {position}")

4.2 移动指针

with open('test.txt', 'r') as f:
    f.seek(0)  # 回到文件开头
    f.seek(5)  # 移动到第5个字符

注意

在文本模式下，seek() 只支持从文件开头计算的偏移量。

五、路径处理

5.1 os 模块

import os

# 获取当前工作目录
print(os.getcwd())

# 列出目录内容
print(os.listdir('.'))

# 判断文件/目录是否存在
print(os.path.exists('file.txt'))

# 判断是否为文件
print(os.path.isfile('file.txt'))

# 判断是否为目录
print(os.path.isdir('folder'))

# 获取文件大小
print(os.path.getsize('file.txt'))

# 创建目录
os.mkdir('new_folder')

# 删除文件
os.remove('file.txt')

# 重命名
os.rename('old.txt', 'new.txt')

5.2 pathlib 模块（推荐）

from pathlib import Path

# 创建路径对象
p = Path('folder/subfolder/file.txt')

# 检查存在
print(p.exists())

# 获取父目录
print(p.parent)

# 获取文件名
print(p.name)
print(p.stem)  # 不带扩展名

# 获取扩展名
print(p.suffix)

# 创建目录
Path('new_folder').mkdir(parents=True, exist_ok=True)

# 遍历目录
for item in Path('.').iterdir():
    print(item.name)

5.3 路径拼接

from pathlib import Path

# 拼接路径
base = Path('/home/user')
file = base / 'documents' / 'file.txt'
print(file)  # /home/user/documents/file.txt

六、JSON 文件操作

6.1 读取 JSON

import json

with open('data.json', 'r', encoding='utf-8') as f:
    data = json.load(f)
    print(data)

6.2 写入 JSON

import json

data = {
    'name': '张三',
    'age': 25,
    'skills': ['Python', 'Java', 'C++']
}

with open('data.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=4)

提示

  • ensure_ascii=False：保存中文原文
  • indent=4：格式化缩进

七、CSV 文件操作

7.1 读取 CSV

import csv

with open('data.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

7.2 写入 CSV

import csv

data = [
    ['姓名', '年龄', '城市'],
    ['张三', '25', '北京'],
    ['李四', '30', '上海']
]

with open('output.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.writer(f)
    writer.writerows(data)

7.3 读取为字典

import csv

with open('data.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row['姓名'], row['年龄'])

八、文件备份与移动

8.1 复制文件

import shutil

# 复制文件
shutil.copy('source.txt', 'dest.txt')

# 复制文件及权限
shutil.copy2('source.txt', 'dest.txt')

8.2 移动文件

import shutil

# 移动文件
shutil.move('source.txt', 'dest_folder/')

# 重命名
shutil.move('old_name.txt', 'new_name.txt')

8.3 压缩与解压

import shutil

# 压缩文件夹
shutil.make_archive('backup', 'zip', 'folder_to_backup')

# 解压
shutil.unzip('backup.zip', 'extract_here')

九、文件批量处理

9.1 批量重命名

import os

folder = 'images'
for filename in os.listdir(folder):
    if filename.endswith('.jpg'):
        new_name = f"img_{filename}"
        os.rename(os.path.join(folder, filename), os.path.join(folder, new_name))

9.2 批量读取多个文件

from pathlib import Path

folder = Path('docs')
for file in folder.glob('*.txt'):
    print(f"读取: {file.name}")
    print(file.read_text())

十、注意事项

最佳实践

  1. 使用 with 语句管理文件资源
  2. 指定编码 encoding='utf-8'
  3. 使用 pathlib 模块处理路径（更面向对象）
  4. 大文件使用流式读取
  5. 处理好异常，确保文件正确关闭

注意

  • 写入模式 w 会覆盖原文件，追加模式 a 不会
  • 读取二进制文件使用 rb 模式
  • 跨平台路径使用 pathlib
