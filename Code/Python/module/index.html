Python 模块与包

概述

模块是 Python 代码组织的基本单位，包是包含多个模块的目录。掌握模块和包的使用对于构建大型 Python 应用至关重要。

一、模块基础

1.1 什么是模块

每个 .py 文件都是一个模块，可以包含函数、类、变量等。

# my_module.py
"""这是我的模块"""

# 模块级变量
VERSION = "1.0.0"

# 模块级函数
def greet(name):
    return f"你好, {name}!"

# 模块级类
class Calculator:
    @staticmethod
    def add(a, b):
        return a + b

代码说明：一个简单的模块示例，包含变量、函数和类。

1.2 导入模块

# 方式1：导入整个模块
import my_module

print(my_module.VERSION)
print(my_module.greet("张三"))
print(my_module.Calculator.add(3, 5))

# 方式2：导入特定内容
from my_module import greet, VERSION

print(greet("李四"))
print(VERSION)

# 方式3：导入并起别名
import my_module as mm

print(mm.greet("王五"))

# 方式4：导入所有内容（不推荐）
from my_module import *

1.3 模块的特殊变量

# my_module.py 内容
print("__name__:", __name__)  # 模块名
print("__file__:", __file__)  # 模块文件路径
print("__doc__:", __doc__)    # 模块文档

# 当直接运行模块时，__name__ 为 "__main__"
if __name__ == "__main__":
    print("直接运行此模块")
else:
    print("被导入使用")

提示

利用 __name__ == "__main__" 可以让模块在被导入时不执行测试代码。

二、包

2.1 什么是包

包是一个包含 __init__.py 文件的目录，用于组织多个模块。

mypackage/
├── __init__.py
├── module1.py
├── module2.py
└── subpackage/
    ├── __init__.py
    └── module3.py

2.2 包的使用

# 导入整个包
import mypackage

# 导入模块
from mypackage import module1

# 导入包中的特定内容
from mypackage.module1 import my_function

2.3 init.py

# mypackage/__init__.py
"""包初始化"""

# 方式1：导入子模块
from . import module1
from . import module2

# 方式2：指定导出内容
__all__ = ['module1', 'module2']

# 包级变量
VERSION = "1.0.0"

2.4 相对导入

# mypackage/subpackage/module3.py

# 相对导入
from .. import module1           # 导入上级包模块
from ..module2 import my_func    # 导入上级包中的模块
from . import my_local_func      # 导入同级模块

注意

相对导入不能用于直接运行的模块。

三、模块搜索路径

3.1 搜索顺序

import sys

# 打印模块搜索路径
for path in sys.path:
    print(path)

搜索顺序：

  1. 当前目录
  2. 环境变量 PYTHONPATH
  3. 安装目录

3.2 添加自定义路径

import sys

# 添加自定义路径
sys.path.insert(0, '/path/to/your/module')

四、标准库常用模块

4.1 datetime 模块

import datetime

# 获取当前时间
now = datetime.datetime.now()
print(now)  # 2025-04-29 12:00:00

# 格式化
print(now.strftime("%Y-%m-%d %H:%M:%S"))

# 创建指定时间
dt = datetime.datetime(2025, 1, 1, 12, 0, 0)
print(dt)

# 时间戳
timestamp = now.timestamp()
print(timestamp)

# 时间差
delta = datetime.timedelta(days=7)
new_date = now + delta
print(new_date)

4.2 os 模块

import os

# 目录操作
os.makedirs('new_folder', exist_ok=True)
os.rmdir('empty_folder')
os.rename('old', 'new')

# 文件操作
os.remove('file.txt')

# 获取信息
print(os.getcwd())          # 当前目录
print(os.listdir('.'))      # 目录内容
print(os.path.exists('f'))   # 是否存在
print(os.path.isfile('f'))  # 是否为文件
print(os.path.isdir('f'))   # 是否为目录

4.3 json 模块

import json

# 序列化
data = {'name': '张三', 'age': 25}
json_str = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str)

# 反序列化
parsed = json.loads(json_str)
print(parsed)

4.4 random 模块

import random

# 随机整数
print(random.randint(1, 10))

# 随机浮点数
print(random.random())

# 随机选择
items = ['a', 'b', 'c', 'd']
print(random.choice(items))

# 随机打乱
random.shuffle(items)
print(items)

# 随机抽样
print(random.sample(items, 2))

4.5 collections 模块

from collections import Counter, defaultdict, OrderedDict

# Counter - 计数器
cnt = Counter(['a', 'b', 'c', 'a', 'a', 'b'])
print(cnt)           # Counter({'a': 3, 'b': 2, 'c': 1})
print(cnt['a'])     # 3

# defaultdict - 默认字典
dd = defaultdict(int)
dd['count'] += 1
print(dd['count'])  # 1

# OrderedDict - 有序字典
od = OrderedDict()
od['a'] = 1
od['b'] = 2
print(od)

五、第三方库

5.1 pip 使用

# 安装包
pip install requests

# 升级包
pip install --upgrade requests

# 卸载包
pip uninstall requests

# 查看已安装的包
pip list

# 导出依赖
pip freeze > requirements.txt

# 从文件安装
pip install -r requirements.txt

5.2 虚拟环境

# 创建虚拟环境
python -m venv myenv

# 激活（Windows）
myenv\Scripts\activate

# 激活（Linux/Mac）
source myenv/bin/activate

# 退出
deactivate

六、模块版本管理

6.1 version

# mymodule/__init__.py
__version__ = "1.2.3"

import mymodule
print(mymodule.__version__)

6.2 版本兼容检查

import sys

# 检查 Python 版本
if sys.version_info < (3, 8):
    raise Exception("需要 Python 3.8+")

# 检查模块版本
try:
    import numpy
except ImportError:
    raise ImportError("需要安装 numpy: pip install numpy")

七、项目结构示例

7.1 标准项目结构

myproject/
├── README.md
├── requirements.txt
├── setup.py
├── mypackage/
│   ├── __init__.py
│   ├── module1.py
│   ├── module2.py
│   └── utils/

├── tests/
│   ├── __init__.py
│   └── test_module1.py
└── docs/

7.2 setup.py 配置

from setuptools import setup, find_packages

setup(
    name="mypackage",
    version="1.0.0",
    description="我的 Python 包",
    author="张三",
    author_email="zhangsan@example.com",
    packages=find_packages(),
    install_requires=[
        "requests>=2.25.0",
    ],
    python_requires=">=3.8",
)
