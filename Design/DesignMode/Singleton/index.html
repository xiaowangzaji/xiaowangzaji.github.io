单例模式

约 228 字小于 1 分钟

2025-10-07

Singleton 模式是设计模式中最为简单、最为常见、最容易实现，也是最应该熟悉和掌握的模式。Singleton 模式就是一个类只创建一个唯一的对象，即一次创建多次使用。

实现单例模式的步骤： 1、构造函数私有化 2、增加静态私有的当前类的指针变量 3、提供静态对外接口,可以让用户获得单例对象

单例分为懒汉式和饿汉式

懒汉式：解决了饿汉式内存浪费问题，但是线程不安全的，可以通过互斥量mutex.lock()和mutex.unlock()来解决 饿汉式：还没有使用该单例对象，该单例对象就已经被加载到内存了，在对象过多时会造成内存浪费

Factory.h
#pragma once

#include "Product.h"

// 工厂基类
class Factory
{
public:
  virtual AbstractApple *CreateApple() = 0;
  virtual AbstractBanana *CreateBanana() = 0;
  virtual ~Factory() {}
};

// 中国工厂
class ChinaFactory : public Factory
{
  virtual AbstractApple *CreateApple() override;
  virtual AbstractBanana *CreateBanana() override;
};

// 美国工厂
class USAFactory : public Factory
{
  virtual AbstractApple *CreateApple() override;
  virtual AbstractBanana *CreateBanana() override;
};

main.cpp
#include "Factory.h"
#include "Product.h"

int main()
{
  Factory *factory = new ChinaFactory();
  ProductFruit *product = factory->CreateApple();

  product->showName();

  delete product;
  delete factory;
  return 0;
}
