第11章 关联容器

11.0 关联容器核心概念

关联容器与顺序容器的核心区别在于：元素按关键字（key）存储和访问，而非按位置。标准库提供两类关联容器：

  • 有序关联容器：按关键字有序排列（默认用<比较），包括map/set/multimap/multiset。
  • 无序关联容器：按哈希表组织（不保证顺序），包括unordered_map/unordered_set/unordered_multimap/unordered_multiset。

11.0.1 容器分类与头文件

容器类型特点头文件
map关键字唯一，键值对（key-value）<map>
set关键字唯一，仅存关键字（key即value）<set>
multimap关键字可重复，键值对<map>
multiset关键字可重复，仅存关键字<set>
unordered_map关键字唯一，哈希组织，键值对<unordered_map>
unordered_set关键字唯一，哈希组织，仅存关键字<unordered_set>
unordered_multimap关键字可重复，哈希组织，键值对<unordered_map>
unordered_multiset关键字可重复，哈希组织，仅存关键字<unordered_set>

11.1 关联容器的基本使用

11.1.1 使用map（键值对容器）

map是“字典”式容器，每个元素是pair<const key_type, mapped_type>（关键字不可修改，值可修改），典型用途是“键值映射”（如单词计数）。

示例：单词计数

#include <map>
#include <string>
#include <iostream>
using namespace std;

int main() {
    map<string, int> word_count;  // 关键字：string（单词），值：int（计数）
    string word;
    while (cin >> word) {
        // 若word不在map中，会自动插入（值默认初始化0），再++
        ++word_count[word];
    }
    // 范围for遍历map（auto自动推导为pair<const string, int>）
    for (const auto& pair : word_count) {
        cout << pair.first << ": " << pair.second << endl;
    }
    return 0;
}

11.1.2 使用set（关键字容器）

set仅存储关键字，且关键字唯一、不可修改，典型用途是“去重”或“判断元素是否存在”。

示例：过滤重复单词

#include <set>
#include <string>
#include <iostream>
using namespace std;

int main() {
    set<string> unique_words;  // 存储不重复的单词
    string word;
    while (cin >> word) {
        unique_words.insert(word);  // 重复单词会自动忽略
    }
    // 遍历set（迭代器指向关键字本身）
    for (const auto& word : unique_words) {
        cout << word << " ";
    }
    return 0;
}

11.2 关联容器概述

11.2.1 通用操作（与顺序容器对比）

关联容器支持大部分顺序容器的通用操作（如begin()/end()/size()/empty()/swap()），但有以下关键差异：

  1. 不支持位置相关操作：如push_back()/push_front()/insert(pos, val)（元素位置由关键字决定）。
  2. 迭代器特性：有序关联容器的迭代器是双向迭代器（支持++/--），无序关联容器的迭代器是前向迭代器（仅支持++）。
  3. 构造函数无大小参数：关联容器无法通过“大小+默认值”构造（如map<int, int> m(10);非法），需通过迭代器范围或初始化列表构造。

11.2.2 关联容器专属类型别名

类型别名含义适用容器
key_type关键字的类型所有关联容器
mapped_type键值对中“值”的类型仅map/unordered_map/multimap/unordered_multimap
value_type容器元素类型：
- set：同key_type（不可修改）
- map：pair<const key_type, mapped_type>		所有关联容器

示例：类型别名使用

map<string, int>::key_type k = "apple";       // k: string
map<string, int>::mapped_type v = 5;          // v: int
map<string, int>::value_type p = {"apple", 5};// p: pair<const string, int>
set<int>::value_type s_val = 10;              // s_val: int（不可修改）

11.2.3 关键字类型的要求

1. 有序关联容器（map/set等）

关键字类型需支持严格弱序（类似<，可自定义），满足：

  • 不可自反：k < k为false。
  • 传递性：若k1 < k2且k2 < k3，则k1 < k3。
  • 等价性：若k1不小于k2且k2不小于k1，则k1与k2等价（容器视为相同关键字）。
自定义比较函数

若关键字类型未重载<，需自定义比较函数，并在容器定义时指定：

#include <set>
#include "Sales_data.h"  // 自定义类，含isbn()成员函数

// 自定义比较函数：按ISBN升序排序
bool compareIsbn(const Sales_data& lhs, const Sales_data& rhs) {
    return lhs.isbn() < rhs.isbn();
}

// 定义multiset，指定比较函数类型（函数指针）和函数对象
multiset<Sales_data, decltype(compareIsbn)*> bookstore(compareIsbn);

2. 无序关联容器（unordered_map等）

关键字类型需满足：

  • 支持==运算符（判断关键字是否相等）。
  • 可计算哈希值（标准库为内置类型、string、智能指针提供默认哈希函数，自定义类型需手动提供）。

11.2.4 pair类型（键值对基础）

pair是存储两个值的模板类型，定义在<utility>头文件中，是map的元素类型基础。

1. pair的定义与初始化

初始化方式示例
直接构造pair<string, int> p("apple", 5);
列表初始化pair<string, int> p = {"apple", 5};
make_pair（自动推导类型）auto p = make_pair("apple", 5);

2. pair的核心操作

操作含义
p.first访问第一个成员（关键字）
p.second访问第二个成员（值）
p1 == p2两个pair的first和second均相等时为真
p1 < p2先比较first，再比较second

示例：函数返回pair

#include <utility>
#include <string>

// 返回pair的函数（列表初始化）
pair<string, int> getWordCount(const string& word) {
    return {word, 1};  // 列表初始化pair
}

// 隐式构造返回值
pair<string, int> getEmptyPair() {
    return pair<string, int>();  // 默认初始化（空string，0）
}

11.3 关联容器的核心操作

11.3.1 迭代器操作

1. 迭代器遍历

  • 有序关联容器：迭代器按关键字升序遍历（如map的迭代器从最小关键字到最大关键字）。
  • 无序关联容器：迭代器顺序不确定（由哈希函数决定）。

2. 迭代器解引用

  • set的迭代器：解引用得到key_type（不可修改）。
  • map的迭代器：解引用得到pair<const key_type, mapped_type>（关键字不可修改，值可修改）。

示例：map迭代器修改值

map<string, int> word_count = {{"apple", 1}, {"banana", 2}};
auto it = word_count.begin();
it->second = 3;  // 合法：修改值（second）
// it->first = "pear";  // 非法：关键字（first）不可修改

3. 关联容器与泛型算法

关联容器的迭代器不支持随机访问，且元素位置由关键字决定，因此泛型算法的适用场景有限：

  • 适合作为源序列（如copy元素到其他容器）。
  • 适合作为目的序列（如用insert插入元素）。
  • 不适合需要修改元素位置的算法（如sort，关联容器元素位置不可变）。

11.3.2 添加元素

关联容器通过insert或emplace添加元素，insert支持多种参数形式：

操作语法示例说明
插入单个元素c.insert(val);val为value_type，返回pair<iterator, bool>（bool表示是否插入成功）
插入迭代器范围c.insert(beg, end);插入[beg, end)范围内的元素，返回void
插入初始化列表c.insert({val1, val2, ...});插入列表中的元素，返回void
提示位置插入c.insert(pos, val);pos为迭代器（提示搜索位置），返回指向插入元素的迭代器
原位构造元素c.emplace(args);用args构造value_type元素，避免临时对象拷贝，返回值同insert(val)

示例1：map插入元素

map<string, int> m;
// 方法1：列表初始化（推荐）
m.insert({"apple", 1});
// 方法2：make_pair
m.insert(make_pair("banana", 2));
// 方法3：显式构造pair
m.insert(pair<string, int>("orange", 3));
// 方法4：emplace（直接构造pair）
m.emplace("pear", 4);

// 检测插入结果
auto ret = m.insert({"apple", 5});
if (!ret.second) {
    // 插入失败（apple已存在），更新值
    ret.first->second = 5;
}

示例2：multimap插入元素（关键字可重复）

multimap<string, int> mm;
// 插入重复关键字（均成功）
mm.insert({"math", 90});
mm.insert({"math", 85});
// 插入单个元素返回指向新元素的迭代器（无bool值）
auto it = mm.insert({"math", 95});

11.3.3 删除元素

关联容器的erase支持三种形式，返回值因参数不同而异：

操作语法示例说明
删除指定迭代器元素c.erase(it);删除it指向的元素，返回void（区别于顺序容器的迭代器返回值）
删除迭代器范围c.erase(beg, end);删除[beg, end)范围内的元素，返回void
删除指定关键字元素c.erase(key);删除所有关键字为key的元素，返回删除的元素个数

示例1：删除指定关键字

map<string, int> m = {{"apple", 1}, {"banana", 2}, {"apple", 3}};
size_t cnt = m.erase("apple");  // cnt=1（apple仅出现一次）

示例2：遍历删除元素

// map遍历删除（注意迭代器失效问题）
map<int, int> m = {{1,0}, {2,1}, {3,0}};
for (auto it = m.begin(); it != m.end(); ) {
    if (it->second == 0) {
        m.erase(it++);  // 先递增迭代器，再删除原位置元素
    } else {
        ++it;
    }
}

11.3.4 访问元素（map专属）

map和unordered_map支持下标操作和at()函数，set无此操作（需通过迭代器访问）。

1. 下标操作（c[key]）

  • 若key在map中，返回mapped_type的引用（可修改）。
  • 若key不在map中，自动插入该关键字（值为默认初始化），再返回引用。

2. at()函数（c.at(key)）

  • 功能与下标类似，但带参数检查：若key不在map中，抛出out_of_range异常。
  • 支持const版本（下标操作不支持const map）。

示例：访问map元素

map<string, int> m = {{"apple", 1}};
// 下标操作
m["banana"] = 2;  // 插入banana，值为2
cout << m["apple"];  // 输出1

// at()函数
try {
    m.at("orange");  // 抛出out_of_range异常（orange不存在）
} catch (out_of_range& e) {
    cerr << e.what() << endl;
}

// const map仅支持at()
const map<string, int> cm = {{"apple", 1}};
// cm["apple"];  // 非法：const map无下标操作
cout << cm.at("apple");  // 合法：输出1

11.3.5 查找元素（通用操作）

所有关联容器均支持以下查找操作，适用于不同场景：

操作语法示例说明
find(key)auto it = c.find(key);返回指向关键字为key的迭代器，不存在则返回end()
count(key)size_t cnt = c.count(key);返回关键字为key的元素个数（非重复容器为0或1）
lower_bound(key)auto it = c.lower_bound(key);返回指向第一个不小于key的元素的迭代器（仅有序容器）
upper_bound(key)auto it = c.upper_bound(key);返回指向第一个大于key的元素的迭代器（仅有序容器）
equal_range(key)auto range = c.equal_range(key);返回pair<iterator, iterator>，表示关键字为key的元素范围（仅有序容器）

示例1：基础查找（非重复容器）

set<int> s = {1,3,5,7};
auto it = s.find(3);  // it指向3
size_t cnt = s.count(3);  // cnt=1
auto it_not = s.find(4);  // it_not = s.end()

示例2：multimap查找所有相同关键字元素

multimap<string, int> mm = {{"math", 90}, {"math", 85}, {"english", 88}};
// 方法1：equal_range（推荐）
auto range = mm.equal_range("math");
for (auto it = range.first; it != range.second; ++it) {
    cout << it->second << " ";  // 输出90 85
}

// 方法2：lower_bound + upper_bound
auto beg = mm.lower_bound("math");
auto end = mm.upper_bound("math");
for (auto it = beg; it != end; ++it) {
    cout << it->second << " ";  // 输出90 85
}

11.4 无序关联容器

无序关联容器（如unordered_map）使用哈希表存储元素，通过哈希函数将关键字映射到“桶”（bucket），查找效率平均为O(1)（最坏为O(n)），适合关键字无排序需求的场景。

11.4.1 无序容器的核心特性

  1. 桶组织：元素按哈希值分组存储在桶中，相同哈希值的元素在同一桶中。
  2. 迭代器顺序：遍历顺序与关键字无关，仅与哈希函数和桶的大小有关。
  3. 关键字要求：需支持==和哈希函数（自定义类型需手动提供）。

11.4.2 桶管理操作

无序容器提供一组操作用于管理桶，优化性能：

操作语法示例说明
bucket_count()size_t n = c.bucket_count();返回当前使用的桶的数量
bucket_size(n)size_t s = c.bucket_size(0);返回第n个桶中的元素个数
bucket(key)size_t b = c.bucket("apple");返回关键字key所在的桶编号
load_factor()float f = c.load_factor();返回每个桶的平均元素数量（负载因子）
max_load_factor()c.max_load_factor(0.7);设置最大负载因子（超过则扩容）
rehash(n)c.rehash(100);重组存储，使桶数不小于n
reserve(n)c.reserve(1000);预留空间，使容器可存储n个元素而不扩容

示例：优化桶性能

unordered_map<string, int> um;
um.reserve(1000);  // 预留空间，避免频繁扩容
for (int i=0; i<1000; ++i) {
    um.insert({to_string(i), i});
}
cout << "桶数：" << um.bucket_count() << endl;  // 输出大于1000的桶数
cout << "负载因子：" << um.load_factor() << endl;  // 输出平均桶元素数

11.4.3 自定义哈希函数（无序容器专属）

若需用自定义类型作为无序容器的关键字，需提供：

  1. 哈希函数：计算该类型的哈希值。
  2. ==运算符：判断两个对象是否相等。

示例：自定义Sales_data的哈希容器

#include <unordered_set>
#include "Sales_data.h"

// 1. 自定义哈希函数：基于ISBN的哈希值
size_t hashSalesData(const Sales_data& sd) {
    // 使用标准库hash<string>计算ISBN的哈希值
    return hash<string>()(sd.isbn());
}

// 2. 自定义==运算符（可作为函数或类的友元）
bool eqSalesData(const Sales_data& lhs, const Sales_data& rhs) {
    return lhs.isbn() == rhs.isbn();
}

// 3. 定义unordered_multiset，指定哈希函数和==函数类型
using SDSet = unordered_multiset<
    Sales_data,
    decltype(hashSalesData)*,  // 哈希函数类型（函数指针）
    decltype(eqSalesData)*    // ==函数类型（函数指针）
>;

// 4. 初始化容器（传入函数对象）
SDSet sd_set(10, hashSalesData, eqSalesData);

11.5 关联容器的选择原则

  1. 有序 vs 无序：
    • 需按关键字排序：选map/set/multimap/multiset。
    • 无需排序，追求查找效率：选unordered_map/unordered_set（平均O(1)查找）。
  2. 关键字是否重复：
    • 关键字唯一：选map/set/unordered_map/unordered_set。
    • 关键字可重复：选multimap/multiset/unordered_multimap/unordered_multiset。
  3. 存储键值对 vs 仅存储关键字：
    • 需键值映射（如计数、字典）：选map/multimap/unordered_map/unordered_multimap。
    • 仅需去重或存在性判断：选set/multiset/unordered_set/unordered_multiset。
