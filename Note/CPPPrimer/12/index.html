第12章 动态内存

约 2498 字大约 8 分钟

12.0 内存分类与特性

C++ 程序使用三种内存类型：

  • 静态内存：存储全局变量、局部 static 对象、类 static 数据成员，生存期贯穿程序始终。
  • 栈内存：存储函数内的非 static 对象，由编译器自动分配和释放，生存期局限于函数调用期间。
  • 堆内存（动态内存）：存储动态分配的对象，由程序员显式管理，生存期由 new/delete 或智能指针控制。

堆内存与栈内存的核心区别

特性栈内存堆内存
管理方式编译器自动分配/释放程序员通过 new/delete 手动管理
空间大小较小（通常 1-2MB），连续内存区域较大（取决于系统虚拟内存），非连续区域
分配效率快（直接调整栈顶指针）慢（需搜索空闲内存块）
存储内容函数参数、局部变量、返回地址等由程序员定义的数据（动态对象）
异常处理栈溢出错误分配失败时抛出 bad_alloc 异常

12.1 动态内存管理与智能指针

C++ 提供两种动态内存管理方式：

  1. 原始指针 + new/delete（易出错，需手动维护）。
  2. 智能指针（自动管理内存，推荐使用）。

智能指针定义在 <memory> 头文件中，包括：

  • shared_ptr：允许多个指针共享一个对象。
  • unique_ptr：独占一个对象的所有权。
  • weak_ptr：弱引用，不控制对象生存期，配合 shared_ptr 使用。

12.1.1 shared_ptr 类

shared_ptr 是模板类，需指定指向的对象类型，通过引用计数管理对象生存期：

  • 每次拷贝 shared_ptr，引用计数递增。
  • 每次销毁 shared_ptr（如超出作用域），引用计数递减。
  • 引用计数为 0 时，自动释放对象内存。

1. shared_ptr 的定义与初始化

#include <memory>
using namespace std;

// 定义方式
shared_ptr<string> p1;                  // 空指针（默认初始化）
shared_ptr<int> p2(new int(10));        // 绑定到动态分配的 int（值为10）
shared_ptr<int> p3 = make_shared<int>(20);  // 推荐：通过 make_shared 构造（最安全）
auto p4 = make_shared<string>("hello"); // 自动推导类型

最佳实践：优先使用 make_shared<T>(args) 构造 shared_ptr，避免直接使用 new，减少内存泄漏风险。

2. shared_ptr 核心操作

操作说明
p->mem访问对象成员（类似指针）
*p解引用指针
p.get()返回内置指针（谨慎使用，避免悬空）
p.use_count()返回引用计数（用于调试）
p.unique()若引用计数为 1，返回 true
p.reset()释放所有权，引用计数递减
p.reset(q)重新绑定到内置指针 q

3. 引用计数的工作机制

auto p = make_shared<int>(42);  // 引用计数 = 1
auto q = p;                     // 引用计数 = 2（p和q共享对象）
p.reset();                      // 引用计数 = 1（p释放所有权）
q.reset();                      // 引用计数 = 0（对象被自动释放）

4. 实例：StrBlob 类（共享动态内存）

#include <vector>
#include <string>
#include <memory>
#include <exception>

class StrBlob {
public:
    using size_type = std::vector<std::string>::size_type;
    StrBlob() : data(std::make_shared<std::vector<std::string>>()) {}
    StrBlob(std::initializer_list<std::string> il) 
        : data(std::make_shared<std::vector<std::string>>(il)) {}

    size_type size() const { return data->size(); }
    bool empty() const { return data->empty(); }

    void push_back(const std::string& t) { data->push_back(t); }
    void pop_back() {
        check(0, "pop_back on empty StrBlob");
        data->pop_back();
    }

    // 重载普通和 const 版本的元素访问函数
    std::string& front() {
        check(0, "front on empty StrBlob");
        return data->front();
    }
    const std::string& front() const {
        check(0, "front on empty StrBlob");
        return data->front();
    }

    std::string& back() {
        check(0, "back on empty StrBlob");
        return data->back();
    }
    const std::string& back() const {
        check(0, "back on empty StrBlob");
        return data->back();
    }

private:
    void check(size_type i, const std::string& msg) const {
        if (i >= data->size())
            throw std::out_of_range(msg);
    }

    std::shared_ptr<std::vector<std::string>> data;  // 共享vector
};

12.1.2 直接管理内存（new/delete）

直接使用 new 分配内存、delete 释放内存，需手动保证配对使用，否则易导致内存泄漏或悬空指针。

1. new 动态分配与初始化

int* p1 = new int;               // 默认初始化（值未定义）
int* p2 = new int(10);           // 直接初始化（值为10）
int* p3 = new int();             // 值初始化（值为0）
string* p4 = new string(5, 'a'); // 构造 "aaaaa"
vector<int>* p5 = new vector<int>{1, 2, 3}; // 列表初始化

2. delete 释放内存

delete p1;  // 销毁p1指向的对象并释放内存
delete p2;  // 释放后，指针变为悬空指针（建议置空）
p2 = nullptr;

3. 常见错误

  • 内存泄漏：忘记 delete 动态内存（如函数返回前未释放）。
  • 悬空指针：delete 后继续使用指针。
  • 重复释放：对同一指针多次 delete。

12.1.3 shared_ptr 与 new 的结合使用

shared_ptr 可绑定到 new 返回的指针，但需注意：

  • 智能指针的构造函数是 explicit 的，必须直接初始化（不能隐式转换）。
  • 避免用同一原始指针初始化多个 shared_ptr（导致重复释放）。
shared_ptr<int> p1(new int(10));  // 正确：直接初始化
// shared_ptr<int> p2 = new int(10);  // 错误：隐式转换不允许

int* raw_ptr = new int(20);
shared_ptr<int> p3(raw_ptr);
// shared_ptr<int> p4(raw_ptr);  // 错误：p3和p4独立管理同一内存，导致重复释放

12.1.4 unique_ptr 类

unique_ptr 独占对象所有权，不支持拷贝和赋值，但可通过 release() 或 reset() 转移所有权。

1. 定义与初始化

unique_ptr<int> u1(new int(10));  // 绑定到动态int
unique_ptr<string> u2;            // 空指针
// unique_ptr<int> u3(u1);  // 错误：不能拷贝

2. 所有权转移

unique_ptr<int> u4(u1.release());  // u1释放所有权，u4接管
u4.reset(new int(20));             // 释放原有内存，绑定新对象

3. 操作特性

  • 支持 *、->、get() 等指针操作。
  • 可作为函数返回值（编译器允许临时对象的拷贝）。

12.1.5 weak_ptr 类

weak_ptr 是 shared_ptr 的弱引用，不影响引用计数，用于解决循环引用问题。

1. 核心操作

操作说明
w.lock()返回指向对象的 shared_ptr（若对象存在）
w.expired()若对象已释放，返回 true
w.use_count()返回关联的 shared_ptr 计数

2. 应用场景

auto sp = make_shared<int>(42);
weak_ptr<int> wp(sp);  // 弱引用sp管理的对象

if (auto np = wp.lock()) {  // 检查对象是否存在
    cout << *np << endl;    // 安全访问对象
}

12.2 动态数组

动态数组是指一次分配多个同类型对象的内存块，C++ 提供两种管理方式：new[]/delete[] 和 allocator 类。

12.2.1 new 与数组

  • 分配数组：new T[n]（返回指向首元素的指针）。
  • 释放数组：delete[] p（必须带 []，否则行为未定义）。
int* arr = new int[10];        // 10个未初始化的int
int* arr2 = new int[10]();     // 10个值为0的int
int* arr3 = new int[10]{1,2};  // 前2个初始化，剩余为0

delete[] arr;  // 释放数组（必须用delete[]）

智能指针管理动态数组

  • unique_ptr 直接支持动态数组（自动使用 delete[]）。
  • shared_ptr 需手动指定删除器。
// unique_ptr管理数组
unique_ptr<int[]> u(new int[10]);
u[0] = 1;  // 支持下标访问

// shared_ptr管理数组（需自定义删除器）
shared_ptr<int> sp(new int[10], [](int* p) { delete[] p; });

12.2.2 allocator 类

allocator 类实现内存分配与对象构造的分离，适合需要精细控制内存的场景（如高性能容器）。

核心操作

操作说明
alloc.allocate(n)分配能存储 n 个对象的未构造内存
alloc.construct(p, args)在指针 p 指向的内存中构造对象
alloc.destroy(p)销毁 p 指向的对象（执行析构函数）
alloc.deallocate(p, n)释放 n 个对象的内存（需先销毁对象）

示例：使用 allocator 管理动态内存

#include <memory>
#include <vector>

int main() {
    std::allocator<int> alloc;
    int n = 10;
    auto p = alloc.allocate(n);  // 分配10个int的内存

    auto q = p;
    alloc.construct(q++, 1);     // 构造第一个元素为1
    alloc.construct(q++, 2);     // 构造第二个元素为2

    // 使用对象...
    for (auto r = p; r != q; ++r)
        cout << *r << " ";  // 输出：1 2

    // 销毁对象
    while (q != p)
        alloc.destroy(--q);

    // 释放内存
    alloc.deallocate(p, n);
    return 0;
}

12.3 文本查询程序实例

文本查询程序实现功能：读取文件内容，支持查询单词出现的次数及所在行的文本。

12.3.1 类设计

  • TextQuery 类：存储文件内容，建立单词到行号的映射。
  • QueryResult 类：保存查询结果（单词、出现次数、行号及对应文本）。

12.3.2 代码实现

#include <fstream>
#include <sstream>
#include <vector>
#include <string>
#include <map>
#include <set>
#include <memory>
#include <iostream>

using namespace std;

class QueryResult;  // 前向声明

class TextQuery {
public:
    using line_no = vector<string>::size_type;
    TextQuery(ifstream& in) : text(new vector<string>) {
        string line;
        while (getline(in, line)) {  // 读取每行文本
            text->push_back(line);
            line_no n = text->size() - 1;  // 当前行号
            istringstream iss(line);
            string word;
            while (iss >> word) {  // 拆分单词
                auto& lines = word_map[word];  // 引用行号集合
                if (!lines)  // 若首次出现，初始化集合
                    lines.reset(new set<line_no>);
                lines->insert(n);  // 插入行号
            }
        }
    }

    QueryResult query(const string& word) const;

private:
    shared_ptr<vector<string>> text;  // 存储文件文本
    map<string, shared_ptr<set<line_no>>> word_map;  // 单词到行号的映射
};

class QueryResult {
    friend ostream& print(ostream&, const QueryResult&);
public:
    using line_no = vector<string>::size_type;
    QueryResult(string w, shared_ptr<set<line_no>> ln, shared_ptr<vector<string>> tx)
        : word(w), lines(ln), text(tx) {}

private:
    string word;  // 查询的单词
    shared_ptr<set<line_no>> lines;  // 行号集合
    shared_ptr<vector<string>> text;  // 文本内容
};

QueryResult TextQuery::query(const string& word) const {
    static shared_ptr<set<line_no>> empty_set(new set<line_no>);
    auto it = word_map.find(word);
    if (it == word_map.end())
        return QueryResult(word, empty_set, text);  // 未找到
    else
        return QueryResult(word, it->second, text);  // 返回结果
}

ostream& print(ostream& os, const QueryResult& qr) {
    os << qr.word << " occurs " << qr.lines->size() << " times:\n";
    for (auto num : *qr.lines) {
        os << "\t(line " << num + 1 << ") " << qr.text->at(num) << "\n";
    }
    return os;
}

// 运行查询
void runQueries(ifstream& infile) {
    TextQuery tq(infile);
    while (true) {
        cout << "Enter word to search (q to quit): ";
        string s;
        if (!(cin >> s) || s == "q") break;
        print(cout, tq.query(s)) << endl;
    }
}

int main(int argc, char* argv[]) {
    if (argc != 2) {
        cerr << "Usage: " << argv[0] << " <filename>" << endl;
        return 1;
    }
    ifstream in(argv[1]);
    if (!in) {
        cerr << "Cannot open file: " << argv[1] << endl;
        return 1;
    }
    runQueries(in);
    return 0;
}

12.3.3 核心设计思路

  1. 数据共享：通过 shared_ptr 使 TextQuery 和 QueryResult 共享文本和行号数据，避免拷贝开销。
  2. 高效查询：使用 set 存储行号，保证唯一性和有序性；使用 map 实现单词到行号的快速映射。
  3. 封装结果：QueryResult 封装查询结果，print 函数负责格式化输出，职责分离。
