第 2 章 变量和基本类型

约 4075 字大约 14 分钟

2.1 基本内置类型

基本内置类型分为算术类型和空类型，其中算术类型包含字符、整型数、浮点数和布尔值。

2.1.1 算术类型

算术类型进一步划分为整型（含字符、布尔值）和浮点型两类，各类型有明确的最小尺寸规定。

1. 类型尺寸与特性

类型最小尺寸关键特性
bool未定义取值为 true 或 false
char8位大小等于机器字节，是否带符号由编译器决定
short16位带符号整型
int16位带符号整型，日常整数运算首选
long32位带符号整型
long long64位带符号整型，用于存储超出 int 范围的数值
float32位（4字节）浮点型，含6位有效数字
double64位（8字节）浮点型，含10位有效数字，日常浮点运算首选

2. 字符类型细分

  • char：存储机器基本字符集，大小等于1字节。
  • wchar_t：宽字符类型，用于存储扩展字符集中的字符。
  • char16_t/char32_t：专门用于存储 Unicode 字符集。

3. 类型选择建议

  • 明确数值非负时，选用无符号类型（如 unsigned int）。
  • 整数运算优先用 int，数值过大时用 long long，避免使用 short 和 long。
  • 浮点运算优先用 double，其计算代价与 float 相差不大，但精度更高。

2.1.2 类型转换

不同类型间赋值或运算时会发生自动转换，需注意转换规则与风险。

  1. 浮点转整型：仅保留小数点前部分（如 3.9 转 int 结果为 3）。
  2. 超出无符号类型范围：结果为初始值对该类型最大值加1取模（如 -1 转 8位 unsigned char 结果为 255）。
  3. 超出带符号类型范围：结果未定义，可能导致程序崩溃或异常行为。

特殊场景：含无符号类型的表达式

  • 表达式中同时存在 unsigned 和 int 时，int 会自动转为 unsigned。
  • 无符号数相减若结果为负，会自动加上该类型的模（如 unsigned u=10; int i=-42; u+i 结果为 4294967264）。

2.1.3 字面值常量

字面值是直接出现在代码中的常量（如 123、3.14），其类型可通过前缀/后缀指定。

1. 整型与浮点型字面值

  • 整型：0 开头为八进制，0x/0X 开头为十六进制；默认是带符号类型，优先匹配 int/long/long long 中能容纳其值的最小类型。
  • 浮点型：可写为小数（如 3.14）或科学计数法（如 3.14e2），默认类型为 double。

2. 字符与字符串字面值

  • 单引号括起单个字符（如 'A'），类型为 char；双引号括起字符序列（如 "ABC"），类型为字符数组。
  • 字符串字面值末尾会自动添加空字符 '\0'，实际长度比可见内容多1（如 "A" 长度为2）。
  • 相邻的字符串字面值（仅隔空格/换行）会自动合并（如 "Hello " "World" 等同于 "Hello World"）。

3. 转义序列

用于表示不可见或特殊字符，常见转义序列如下：

  • 换行 \n、制表 \t、退格 \b、报警 \a
  • 双引号 \"、单引号 \'、反斜线 \\、问号 \?
  • 泛化转义：\ 加1-3个八进制数（如 \12 代表换行），或 \x 加任意个十六进制数（如 \x4d 代表 'M'）。

4. 字面值类型指定

通过前缀/后缀修改默认类型，常见规则如下：

字面值类型前缀/后缀示例
无符号整型后缀 u/U12u（unsigned int）
长整型后缀 l/L12l（long）
长整型后缀 ll/LL12ll（long long）
浮点型后缀 f/F3.14f（float）
宽字符前缀 LL'A'（wchar_t）
Unicode 16前缀 uu"ABC"（char16_t）
Unicode 32前缀 UU"ABC"（char32_t）
UTF-8前缀 u8u8"ABC"（char）

注意：整型字面值不能加 f 后缀，若需表示浮点型需写为 12.f。

5. 布尔与指针字面值

  • 布尔字面值：true（真）、false（假）。
  • 指针字面值：nullptr（空指针，替代旧标准的 NULL）。

2.2 变量

C++ 中“变量”和“对象”可互换使用，对象指能存储数据且具有明确类型的内存块。

2.2.1 变量定义

变量定义的核心是初始化——创建变量时赋予初始值（区别于“赋值”：赋值是覆盖已有值）。

1. 初始化方式

  • 普通初始化：int i=0;、int i(0);
  • 列表初始化：int i{0};、int i={0};（内置类型用列表初始化时，若有信息丢失风险，编译器会报错）。

2. 变量初始化规则

  • 函数体内的内置类型变量：未初始化则值未定义（使用会导致运行时故障）。
  • 函数体外的内置类型变量：默认初始化为 0。
  • 类类型变量（如 string）：由类自身定义默认初始化行为（如 string 默认为空串）。

建议：初始化每一个内置类型变量，避免未定义行为。

3. 多变量定义

同一条语句中，可先用已定义变量初始化后续变量（如 double price=109.99, discount=price*0.6;）。

2.2.2 变量声明和定义的关系

  • 声明：告诉编译器变量的名称和类型，不分配内存；需加 extern，且不能赋值（如 extern int i;）。
  • 定义：不仅声明变量，还分配内存；若声明中包含初始化，则自动转为定义（如 extern int i=1; 是定义）。

核心规则：变量只能定义一次，但可多次声明；C++ 是静态类型语言，编译阶段会检查类型合法性。

2.2.3 标识符

标识符是变量、函数等的名称，需遵循以下规则：

  1. 组成：字母、数字、下划线；不能以数字开头，区分大小写。
  2. 禁忌：不能连续出现两个下划线，不能以下划线+大写字母开头；函数体外的标识符不能以下划线开头。
  3. 命名规范：
    • 变量名用小写字母（如 student_count）。
    • 自定义类型名首字母大写（如 Sales_data）。
    • 多单词用驼峰命名法（studentCount）或下划线连接（student_count）。

2.3 复合类型

复合类型基于其他类型定义，核心是引用和指针。

2.3.1 引用

引用是对象的“别名”，与对象绑定后不可更改指向。

1. 引用定义规则

  • 必须初始化，且初始值必须是对象（不能是字面值或表达式）。
  • 引用类型必须与绑定对象的类型一致。
  • 对引用的所有操作，本质是对绑定对象的操作（如 int i=10; int &r=i; r=20; 会使 i 变为 20）。

2. 引用的限制

  • 引用不是对象，因此不能定义“引用的引用”（如 int &(&r)=i; 错误）。

2.3.2 指针

指针是存储对象地址的变量，可更改指向的对象。

1. 指针定义与使用

  • 定义时需指定指向对象的类型（如 int *ip; 是指向 int 的指针）。
  • 指针初始化：未初始化的指针（函数体内）值不确定；可指向对象地址（如 int i=0; int *ip=&i;），或用 nullptr 初始化为空指针。

2. 指针与引用的核心区别

特性指针引用
是否为对象是（可存储地址）否（仅为别名）
指向可更改是（可重定向到其他对象）否（绑定后不可更改）
初始化要求可默认初始化（不推荐）必须初始化
嵌套定义可定义“指针的指针”不可定义“引用的引用”

3. 特殊指针类型

  • 空指针：用 nullptr 表示（推荐），也可用 0 或 NULL（NULL 是预处理变量，值为 0）。
  • void 指针*：可存储任意对象的地址，但无法直接访问对象（需强制类型转换），用途有限。

2.3.3 理解复合类型的声明

声明语句由“基本类型 + 声明符列表”组成，&（引用）和 *（指针）是声明符的一部分，需注意同一条语句中不同变量的类型。

示例分析：

  • int &a=b, &c=b;：a 和 c 都是 int 类型的引用。
  • int *a=nullptr, b=1;：a 是指向 int 的指针，b 是 int 类型变量。

复杂声明解读：从右向左读（如 int* &r=p;：r 是对“指向 int 的指针 p”的引用）。

2.4 const限定符

const 用于定义“只读变量”，即变量值初始化后不可更改。

2.4.1 const的核心规则

  • const 对象必须初始化（如 const int ci=42;）。
  • 默认情况下，const 对象仅在当前文件内有效；若需多文件共享，需在声明和定义前均加 extern（如 extern const int ci=42;）。

2.4.2 const的引用（常量引用）

常量引用是对 const 对象的引用，或绑定到非 const 对象的“只读别名”。

1. 常量引用规则

  • 可绑定 const 对象（如 const int ci=42; const int &r=ci;）。
  • 可绑定非 const 对象（如 int i=42; const int &r=i;），但不能通过引用修改对象值（i 可通过其他方式修改）。
  • 可绑定字面值或表达式（如 const int &r=42;、const int &r=1+2;）——普通引用不可。

2.4.3 指针和const

指针与 const 结合分两种情况：指向常量的指针（底层 const）和常量指针（顶层 const）。

1. 底层const与顶层const

  • 底层const：指针所指对象是 const（不能通过指针修改对象值），指针本身可更改指向（如 const int *p;）。
  • 顶层const：指针本身是 const（不能更改指向），所指对象可修改（如 int *const p=&i;）。

2. 区分方法

从右向左读：

  • const int* const p3;：右侧 const 是顶层（p3 是常量指针），左侧 const 是底层（指向 const int）。
  • int* const p1;：const 在 * 右侧，是顶层（p1 不可更改指向）。

3. 拷贝规则

底层 const 对象不能拷贝给非底层 const 指针/引用（如 const int ci=42; int *p=&ci; 错误）；反之可（非 const 对象会自动转为 const）。

2.4.4 constexpr和常量表达式

  • 常量表达式：值不变且编译阶段可计算的表达式（如 const int a=32;、const int b=a+1;）。
  • constexpr变量：由编译器验证是否为常量表达式，必须用常量表达式初始化（如 constexpr int sz=10;）。

1. constexpr与const的区别

  • constexpr 变量：编译阶段确定值，是“真正的常量”。
  • const 变量：可能是运行时初始化（如 const int sz=get_size();），仅表示“只读”。

2. 字面值类型

constexpr 变量的类型必须是“字面值类型”（算术类型、引用、指针）；自定义类不属于字面值类型。

2.5 处理类型

C++ 提供多种方式简化类型操作：类型别名、auto、decltype。

2.5.1 类型别名

类型别名是给已有类型起新名字，两种定义方式：

  • typedef：typedef double wages;（wages 是 double 的别名）。
  • using（C++11）：using wages=double;（更直观，推荐）。

注意：指针与类型别名

若类型别名是指针，加 const 会使指针本身成为常量（如 typedef char* pstring; const pstring cstr=nullptr;：cstr 是指向 char 的常量指针，而非 const char*）。

2.5.3 decltype 类型指示符

decltype 的核心作用是获取表达式的类型，且会完整保留表达式类型的所有属性（包括顶层 const 和引用），这是它与 auto 的关键区别。

1. decltype 基本使用规则

  • 表达式为变量：直接返回变量的完整类型，包括顶层 const 和引用。

    • 示例1：const int ci = 42; decltype(ci) x = 0; → x 的类型是 const int（保留顶层 const）。
    • 示例2：int &r = i; decltype(r) y = r; → y 的类型是 int&（保留引用，必须初始化）。

  • 表达式为非变量：返回表达式计算结果对应的类型，需注意特殊场景的类型推导。

2. 特殊表达式的类型推导

以下三种场景是 decltype 推导的高频考点，需重点关注：

  1. 解引用指针：解引用操作的结果是“指向对象的引用”，因此 decltype 推导结果为引用类型。

    • 示例：int i = 42; int *p = &i; decltype(*p) c = i; → c 的类型是 int&（必须初始化）。

  2. 变量加括号：给单个变量加一层或多层括号后，表达式会被视为“带括号的变量表达式”，decltype 推导结果为引用类型。

    • 示例1：int i = 42; decltype((i)) d = i; → d 的类型是 int&（必须初始化）。
    • 示例2：decltype(((i))) e = i; → 结果仍为 int&（多层括号不改变推导结果）。
    • 对比：decltype(i) f = i; → f 的类型是 int（无括号，仅返回变量本身类型）。

  3. 赋值表达式：赋值操作的结果是“左值引用”（即赋值运算符左侧的对象），因此 decltype 推导结果为引用类型。

    • 示例：int a = 10, b = 20; decltype(a = b) g = a; → g 的类型是 int&（a = b 结果为 a 的引用）。

3. decltype 与 auto 的核心差异

对比维度decltypeauto
顶层 const 处理保留（如 const int ci; decltype(ci) 是 const int）忽略（如 const int ci; auto b = ci 中 b 是 int）
引用处理保留（如 int& r; decltype(r) 是 int&）忽略（如 int& r; auto c = r 中 c 是 int）
初始化依赖不依赖初始化（可单独获取类型，如 decltype(1 + 2)）必须依赖初始化（需根据初始值推断类型）

2.6 自定义数据结构

C++ 允许通过 struct 定义自定义数据类型，核心用于封装相关数据，是面向对象编程的基础。

2.6.1 定义 Sales_data 类型（自定义结构体示例）

结构体的定义格式为：struct + 结构体名 + 类体（含数据成员） + 分号（分号不可省略）。

1. 基本定义格式

// 空结构体（无数据成员）
struct Sales_data {};

// 含数据成员的结构体，可提供类内初始值
struct Sales_data {
    std::string bookNo;                // 图书编号，无类内初始值
    unsigned units_sold = 0;           // 销售数量，类内初始值为 0
    double revenue = 0.0;              // 销售收入，类内初始值为 0.0
};

2. 类内初始值规则

  • 类内初始值用于初始化数据成员，未提供类内初始值的成员，会按“默认初始化”规则处理（如内置类型未初始化则值未定义）。
  • 赋值方式：可使用花括号 {} 或等号 =，不能使用圆括号 ()。
    • 正确示例：unsigned units_sold = 0; 或 unsigned units_sold{0};。
    • 错误示例：unsigned units_sold(0);（圆括号初始化不支持）。

2.6.3 编写自己的头文件

自定义结构体（如 Sales_data）通常定义在头文件中，需遵循头文件编写规范，避免重复包含导致的编译错误。

1. 头文件核心规范

  • 命名：头文件名应与自定义类型名一致（如 Sales_data 对应 Sales_data.h）。
  • 内容：仅存放“可被多次声明、仅需一次定义”的实体，如结构体、const 变量、constexpr 变量等。
  • 更新：头文件修改后，所有包含该头文件的源文件（.cpp）必须重新编译，以确保使用最新声明。

2. 头文件保护符（避免重复包含）

当多个源文件包含同一头文件时，会导致结构体等实体被重复定义，需通过预处理器指令实现“多次包含仍安全”。

（1）预处理器核心指令
  • #define 标识符：定义一个预处理变量（标识头文件是否已被包含）。
  • #ifndef 标识符：“if not defined”，若预处理变量未定义，则执行后续代码（直至 #endif）。
  • #endif：结束 #ifndef 代码块。
（2）标准使用格式
// Sales_data.h
#ifndef SALES_DATA_H    // 若 SALES_DATA_H 未定义
#define SALES_DATA_H    // 定义 SALES_DATA_H，标记头文件已包含

#include <string>       // 结构体依赖 string 类型，需包含对应头文件

struct Sales_data {
    std::string bookNo;
    unsigned units_sold = 0;
    double revenue = 0.0;
};

#endif                  // 结束 #ifndef 代码块
（3）命名规则

预处理变量（如 SALES_DATA_H）需确保全局唯一，通常采用“头文件名全大写 + 下划线替换小数点”的格式（如 Sales_data.h 对应 SALES_DATA_H），避免与其他头文件冲突。

（4）注意事项
  • 预处理变量无视作用域规则，作用范围为整个源文件（从定义处到文件结束）。
  • 所有自定义头文件都应添加保护符，即使当前仅被一个源文件包含，也需保证可扩展性。
