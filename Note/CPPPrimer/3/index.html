第 3 章 字符串、向量和数组

3.1 命名空间的using声明

using 声明用于简化命名空间中名字的使用，可单独声明某个名字，无需每次加 std:: 前缀。

  • 基本语法：using 命名空间::名字;，例如 using std::cin; 后，可直接使用 cin 而非 std::cin。
  • 核心禁忌：头文件中不应包含 using 声明。头文件内容会被多个源文件包含，using 声明会污染全局命名空间，导致名字冲突。

3.2 标准库类型string

string 是表示可变长字符序列的标准库类型，定义在 std 命名空间中，需包含头文件 <string>。

3.2.1 定义和初始化string对象

string 提供多种初始化方式，核心分为拷贝初始化（用 =）和直接初始化（不用 =），默认初始化会得到空字符串。

1. 常用初始化方式

初始化方式示例说明
默认初始化string s1;s1 为空字符串
拷贝初始化（=）string s1 = s2;s1 是 s2 的副本
直接初始化（字面值）string s1("value");s1 是字面值 "value" 的副本（不含末尾空字符）
直接初始化（重复字符）string s1(n, 'c');s1 包含 n 个字符 'c'（如 3, 'a' 得到 "aaa"）
列表初始化（{}）string s1{"value"};与直接初始化字面值效果一致，优先匹配列表元素

2. 关键注意点

  • 用字符串字面值（如 "value"）初始化 string 时，string 对象不包含字面值末尾的空字符 '\0'，仅拷贝可见字符。
  • 列表初始化时，若花括号内的值无法匹配 string 构造函数（如 string s{10};），会自动转为“值初始化”，即 s 包含 10 个空字符。

3.2.2 string对象上的操作

string 提供丰富的成员函数和运算符，用于读写、判断、修改字符串。

1. 核心操作列表

操作示例说明
读取字符串cin >> s;从输入流读取，忽略开头空白，遇到空白停止（无法读整行）
读取整行getline(cin, s);从输入流读取整行（包括空格），丢弃换行符，存入 s
判断是否为空s.empty();为空返回 true，否则返回 false
获取字符数s.size();返回字符串长度，类型为 string::size_type（无符号）
访问单个字符s[n];访问第 n 个字符（下标从 0 开始），需确保 n < s.size()
字符串拼接s3 = s1 + s2;连接 s1 和 s2，返回新字符串；加号两边至少一个是 string（如 "a"+s1 合法，"a"+"b" 非法）
字符串比较s1 == s2、s1 > s2按字符 ASCII 码比较，逐字符对比，区分大小写（如 "apple" < "banana"）

2. 重点操作详解

（1）getline 函数
  • 作用：读取输入流中一整行内容，包括空格，直到遇到换行符停止。
  • 关键特性：触发返回的换行符会被丢弃，不会存入 string 对象（如输入 "hello\n"，s 中是 "hello"）。
  • 空行处理：若输入开头就是换行符，会得到空字符串（如 getline(cin, s) 遇到空行，s 为空）。
  • 返回值：返回输入流对象（如 cin），可作为条件判断（如 while (getline(cin, s)) { ... }）。
（2）string::size_type 类型
  • 本质：size() 成员函数的返回类型，是无符号整数类型，大小足够存储任意 string 的长度。
  • 使用建议：避免用 int 接收 size() 的结果，无符号数与 int 混用可能导致计算错误（如 s.size() - 1 当 s 为空时，结果为极大值而非 -1）。
  • 简化方式：用 auto 或 decltype 自动推导类型（如 auto len = s.size();）。

3.2.3 处理string对象中的字符

处理 string 单个字符时，常用 <cctype> 头文件中的标准库函数，且可通过范围for循环遍历所有字符。

1. <cctype> 头文件常用函数

这些函数输入为 int 类型（实际是字符的 ASCII 码，范围 -1 <= c <= 255），输出为布尔值或转换后的字符。

函数功能
isalnum(c)判断 c 是否为字母或数字
isalpha(c)判断 c 是否为字母
isdigit(c)判断 c 是否为数字（'0'-'9'）
islower(c)判断 c 是否为小写字母
isupper(c)判断 c 是否为大写字母
tolower(c)将 c 转换为小写字母并返回
toupper(c)将 c 转换为大写字母并返回

建议：使用 C++ 风格头文件 <cctype>，而非 C 风格的 <ctype.h>。<cctype> 中的名字属于 std 命名空间，更符合 C++ 规范。

2. 范围for循环遍历字符

  • 只读遍历：无需修改字符时，用值类型循环变量（如 for (auto c : s) { cout << c; }）。
  • 修改遍历：需修改字符时，循环变量必须是引用类型（如 for (auto &c : s) { c = toupper(c); }，将 s 全部转为大写）。
  • 禁忌：范围for循环中不能改变 string 的大小（如不能在循环内调用 s.push_back(c)），会导致迭代器失效。

3. 下标访问注意事项

  • 下标范围：必须满足 0 <= n < s.size()，否则会触发未定义行为（程序崩溃或异常）。
  • 安全检查：访问前建议用 if (!s.empty()) 判断字符串是否为空（如 s[s.size()-1] 访问最后一个字符，需确保 s 非空）。

3.3 标准库类型vector

vector 是表示可变长数组的类模板，可存储任意类型的对象（需是“可拷贝”类型），定义在 std 命名空间中，需包含头文件 <vector>。

3.3.1 定义和初始化vector对象

vector 是模板，需指定元素类型（如 vector<int>、vector<string>），默认初始化得到空向量。

1. 常用初始化方式

初始化方式示例说明
默认初始化vector<int> v1;v1 为空向量，无元素
拷贝初始化（=）vector<int> v1 = v2;v1 是 v2 的副本（元素类型需相同）
直接初始化（重复值）vector<int> v1(n, val);v1 包含 n 个值为 val 的元素（如 5, 0 得到 [0,0,0,0,0]）
直接初始化（默认值）vector<int> v1(n);v1 包含 n 个默认初始化的元素（内置类型为 0，类类型如 string 为空）
列表初始化（{}）vector<int> v1{1,2,3};v1 包含列表中的元素 1,2,3

2. 初始化规则补充

  • 值初始化：当仅指定元素个数（如 vector<int> v(n)），内置类型元素初始化为 0，类类型元素按其默认构造函数初始化（如 vector<string> v(3) 得到 3 个空字符串）。
  • 列表初始化优先级：若花括号内的元素类型与 vector 元素类型匹配（如 vector<int> v{1,2}），优先按列表初始化；若不匹配（如 vector<string> v{10}），则转为“值初始化”（v 包含 10 个空字符串）。

3.3.2 向vector对象中添加元素

vector 的核心优势是支持高效动态增长，推荐先定义空向量，再通过 push_back 函数添加元素。

1. 核心函数：push_back

  • 功能：在 vector 的末尾添加一个元素，自动扩容（扩容机制由标准库优化，效率较高）。
  • 示例：vector<int> v; v.push_back(1); v.push_back(2); → v 变为 [1,2]。

2. 初始化策略建议

场景推荐做法原因
已知元素个数且所有元素值相同直接初始化（如 vector<int> v(5, 3)）避免多次 push_back，效率更高
已知元素个数但值不同先定义空向量，再 push_back无需提前构造无关元素，更灵活
元素个数未知空向量 + push_back动态适应元素数量，避免空间浪费

3.3.3 其他vector操作

vector 的操作与 string 类似，核心包括判断空、获取大小、访问元素等。

操作示例说明
判断是否为空v.empty();为空返回 true，否则返回 false
获取元素个数v.size();返回元素个数，类型为 vector<T>::size_type（无符号）
访问单个元素v[n];访问第 n 个元素（下标从 0 开始），需确保 n < v.size()
范围遍历for (auto &x : v) { ... }遍历所有元素，引用类型可修改元素值

注意：vector 不支持 string 那样的 + 运算符拼接，需通过 push_back 逐个添加元素实现“拼接”。

3.4 迭代器介绍

迭代器是遍历标准库容器元素的工具，可理解为“泛化的指针”，所有标准库容器（如 string、vector）都支持迭代器，数组不直接支持但可通过指针模拟。

3.4.1 使用迭代器

迭代器通过容器的 begin() 和 end() 成员函数获取，begin() 返回指向第一个元素的迭代器，end() 返回指向尾后元素（容器最后一个元素的下一个位置）的迭代器。

1. 迭代器的基本操作

操作示例说明
获取迭代器auto b = v.begin(), e = v.end();b 指向首元素，e 指向尾后元素
解引用（取元素）*iter返回迭代器 iter 所指元素的引用
访问成员（指针）iter->mem等价于 (*iter).mem，访问所指元素的成员（如 string 的 size()）
迭代器递增++iter迭代器指向下一个元素（前置递增效率更高）
迭代器比较iter == e、iter != e判断迭代器是否指向同一位置（end() 不可解引用）

2. 常量迭代器与普通迭代器

  • 普通迭代器（iterator）：可读写元素，通过 begin()/end() 获取（如 vector<int>::iterator it = v.begin();）。
  • 常量迭代器（const_iterator）：仅可读元素，不可修改，通过 cbegin()/cend() 获取（如 auto it = v.cbegin();），适合遍历const容器或无需修改元素的场景。

3. 关键注意点

  • 若容器为空，begin() 和 end() 返回的迭代器相同（均为尾后迭代器），不可解引用。
  • 迭代器失效：当容器大小改变（如 vector 的 push_back 导致扩容），原迭代器可能失效，后续使用会触发未定义行为。

3.4.2 迭代器运算

string 和 vector 支持额外的迭代器运算（其他容器如 list 不支持），可实现快速定位。

运算示例说明
迭代器 + 整数iter + n迭代器向前移动 n 个元素（需确保不越界）
迭代器 - 整数iter - n迭代器向后移动 n 个元素（需确保不越界）
迭代器 += 整数iter += n等价于 iter = iter + n，原地移动
迭代器 -= 整数iter -= n等价于 iter = iter - n，原地移动
迭代器 - 迭代器iter1 - iter2返回两迭代器之间的元素个数，类型为 difference_type（带符号整数）
迭代器比较（<,>）iter1 > iter2按元素位置比较（如 begin() < end()）

禁忌：迭代器不能相加（如 iter1 + iter2 非法），仅支持相减。

3.5 数组

数组是固定大小的内置数据结构，存储同一类型的元素，大小在定义时必须确定，与 vector 相比灵活性较差（不可动态扩容）。

3.5.1 定义和初始化内置数组

数组的定义格式为 元素类型 数组名[数组大小];，数组大小必须是常量表达式（如字面量、constexpr 变量），不能是普通变量。

1. 常用初始化方式

初始化方式示例说明
默认初始化int a[10];元素值未定义（函数内）或初始化为 0（函数外）
列表初始化（部分元素）int a[5] = {1,2};前 2 个元素为 1,2，剩余元素初始化为 0
列表初始化（省略大小）int a[] = {1,2,3};数组大小自动推导为 3
字符数组（字面值）char a[] = "c++";数组大小为 4（含末尾空字符 '\0'）
字符数组（列表）char a[] = {'c','+','+'};数组大小为 3（不含空字符）

2. 关键禁忌

  • 数组大小不能是变量：如 int n=5; int a[n]; 非法（C++ 不支持变长数组）。
  • 数组不能拷贝或赋值：如 int a[3] = {1,2,3}; int b[[3] = a; 非法，不能直接用一个数组给另一个数组赋值，需逐个元素拷贝。
  • 数组元素不能是引用：引用不是对象，而数组存储的必须是对象（如 int &a[3]; 非法）。

3. 复杂数组类型解读

数组的类型由“元素类型 + 维度”决定，复杂数组（如指针数组、数组指针）需按“由内向外”的顺序解读。

数组定义解读类型说明
int *ptrs[10];先看 ptrs[10]（数组），再看 int*（元素类型）含有 10 个 int* 指针的数组
int (*ptrs)[10] = &arr;先看 (*ptrs)（指针），再看 int[10]（指向的类型）指向“含有 10 个 int 的数组”的指针
int (&ptrs)[10] = arr;先看 (&ptrs)（引用），再看 int[10]（引用的类型）引用“含有 10 个 int 的数组”的引用

3.5.2 访问数组元素

数组元素通过下标访问，下标从 0 开始，范围是 0 <= 下标 < 数组大小，超出范围会触发未定义行为。

1. 下标类型

数组下标的默认类型是 size_t（定义在 <cstddef> 头文件中），是无符号整数类型，与 vector、string 的 size_type 类似。

2. 遍历数组的方式

  • 普通 for 循环：通过下标遍历（如 for (size_t i=0; i<10; ++i) { cout << a[i]; }）。
  • 范围 for 循环：直接遍历所有元素（如 for (auto x : a) { cout << x; }），需注意数组大小在编译时确定。
  • 指针遍历：数组名在多数情况下会隐式转为指向首元素的指针（如 int *p = a; 等价于 int *p = &a[0];），通过指针递增遍历（如 for (int *p=a; p!=a+10; ++p) { cout << *p; }）。

3.5.3 指针和数组

数组与指针关系密切，多数情况下数组名会被当作“指向首元素的指针”处理，这是 C++ 兼容 C 语言的特性。

1. 数组名的隐式转换

  • 数组名作为函数参数、赋值给指针变量时，会隐式转为指向首元素的指针（如 int a[5]; int *p = a; 合法）。
  • 例外情况：数组名用于 sizeof 运算符（sizeof(a) 计算数组总大小）、取地址符 &（&a 得到指向整个数组的指针）时，不发生转换。

2. 数组下标与指针的关系

数组下标运算 a[i] 本质是“指针偏移”，等价于 *(a + i)，即“首元素指针向后移动 i 个位置，再解引用”。

  • 示例：a[2] 等价于 *(a + 2)，*(2 + a) 等价于 2[a]（语法合法，但不推荐使用）。

3. 指针的下标操作

指向数组元素的指针也支持下标运算（如 int *p = a; p[2] 等价于 a[2]），这与 vector、string 的迭代器不同（迭代器不支持下标）。

3.5.4 C风格字符串

C风格字符串不是独立类型，而是以空字符 '\0' 结尾的字符数组，是 C 语言中表示字符串的方式，C++ 为兼容提供支持，但不推荐使用（易引发内存错误）。

1. C风格字符串的定义

  • 正确定义：char str[] = "hello";（末尾自动添加 '\0'，数组大小为 6）。
  • 错误定义：char str[] = {'h','e','l','l','o'};（无 '\0'，不是合法的 C 风格字符串）。

2. 常用C风格字符串函数

C风格字符串的操作需通过 <cstring> 头文件中的函数实现，这些函数不验证参数合法性，需手动确保指针指向合法的、以 '\0' 结尾的字符数组。

函数示例说明
strlen(p)strlen("hello");返回字符串长度（不含 '\0'），结果为 5
strcmp(p1, p2)strcmp("a", "b");比较 p1 和 p2：相等返回 0，p1 小返回负值，p1 大返回正值
strcat(p1, p2)strcat(str1, str2);将 p2 拼接到 p1 末尾，返回 p1；需确保 p1 空间足够
strcpy(p1, p2)strcpy(str1, str2);将 p2 拷贝到 p1，返回 p1；需确保 p1 空间足够

3. 核心风险

  • 无边界检查：strcat、strcpy 可能导致缓冲区溢出，覆盖其他内存数据。
  • 依赖 '\0' 结尾：若字符数组无 '\0'，strlen 等函数会越界访问，导致未定义行为。

3.5.5 与旧代码的接口

C++ 标准库类型（string、vector）与 C 风格数组、字符串可互相转换，以兼容旧代码。

1. string与C风格字符串的转换

  • C风格字符串转 string：可直接用 C 风格字符串初始化 string 或赋值（如 string s = "hello";、string s = str;，str 是 char* 类型）。
  • string转 C风格字符串：需调用 string 的 c_str() 成员函数，返回 const char* 类型的指针（指向以 '\0' 结尾的字符数组），示例：
    string s = "hello";
const char* cp = s.c_str();  // 正确，cp 指向 s 内部的字符数组

    注意：c_str() 返回的指针仅在 string 对象未被修改（如 push_back、赋值）前有效，修改 string 后指针可能失效。

2. 数组与vector的转换

可用数组初始化 vector，通过标准库函数 begin() 和 end()（定义在 <iterator> 头文件中）指定数组的范围（左闭合区间 [begin(arr), end(arr))），示例：

int arr[] = {0, 1, 2, 3, 4};
vector<int> ivec(begin(arr), end(arr));  // ivec 包含数组 arr 的所有元素
vector<int> ivec2(arr + 1, arr + 3);     // ivec2 包含元素 1、2（从 arr[1] 到 arr[2]）

3. 推荐原则

优先使用 string 和 vector，避免直接使用内置数组和 C 风格字符串，减少内存错误和未定义行为的风险。

3.6 多维数组

C++ 中没有真正的多维数组，所谓“多维数组”本质是数组的数组（如二维数组是“存储数组的数组”）。

3.6.1 多维数组的定义和初始化

多维数组的定义格式为 元素类型 数组名[维度1][维度2]...[维度n];，维度必须是常量表达式。

1. 常用初始化方式

初始化方式示例说明
完全初始化（嵌套花括号）int arr[2][3] = {{1,2,3}, {4,5,6}};外层花括号对应第一维度（2个元素，每个是含3个 int 的数组）
完全初始化（省略内层花括号）int arr[2][3] = {1,2,3,4,5,6};按顺序填充所有元素，效果与嵌套花括号一致
部分初始化（嵌套花括号）int arr[2][3] = {{1}, {4,5}};第一行初始化为 [1,0,0]，第二行初始化为 [4,5,0]
值初始化（全0）int arr[2][3] = {0};所有元素初始化为 0

2. 维度省略规则

多维数组中，仅第一维度可以省略，编译器会根据初始化元素个数推导第一维度大小，其他维度必须显式指定，示例：

int arr[][3] = {1,2,3,4,5,6};  // 合法，第一维度推导为 2（6个元素 / 3列 = 2行）
int arr[2][] = {1,2,3,4,5,6};  // 非法，第二维度不能省略

3.6.2 多维数组的访问和遍历

多维数组的元素通过多个下标访问（如二维数组 arr[i][j]，i 是第一维度下标，j 是第二维度下标），遍历需嵌套循环。

1. 下标访问

  • 二维数组 arr[2][3] 中，arr[0] 是第一行的数组（类型为 int[3]），arr[0][0] 是第一行第一列的元素。
  • 指针访问：二维数组名 arr 隐式转为指向第一行数组的指针（类型为 int (*)[3]），通过指针递增遍历行，解引用后得到该行数组的指针（类型为 int*），再遍历列，示例：
    int arr[2][3] = {{1,2,3}, {4,5,6}};
for (int (*row)[3] = arr; row != arr + 2; ++row) {  // 遍历行
    for (int *col = *row; col != *row + 3; ++col) {  // 遍历列
        cout << *col << " ";
    }
}

2. 范围for循环遍历

用范围for循环遍历多维数组时，除最内层循环外，其他循环的控制变量必须是引用类型。若不用引用，数组会隐式转为指针，导致内层循环无法遍历（指针不支持范围for），示例：

int arr[2][3] = {{1,2,3}, {4,5,6}};
// 正确：外层循环控制变量是引用（指向 int[3] 数组）
for (auto &row : arr) {
    for (auto col : row) {
        cout << col << " ";
    }
}

// 错误：外层循环控制变量是值类型，arr[i] 转为 int* 指针，内层循环无法遍历指针
for (auto row : arr) {
    for (auto col : row) {  // 编译错误
        cout << col << " ";
    }
}

3. 类型别名简化代码

多维数组的指针类型较复杂，可通过 typedef 或 using 定义类型别名简化，示例：

// 定义类型别名：int_array 是“含3个 int 的数组”的类型
using int_array = int[3];
// 遍历二维数组
for (int_array &row : arr) {  // row 是 int_array 类型的引用
    for (int col : row) {
        cout << col << " ";
    }
}
