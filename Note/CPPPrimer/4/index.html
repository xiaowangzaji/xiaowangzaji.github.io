第 4 章 表达式和运算符

约 4873 字大约 16 分钟

2025-09-26

4.1 表达式基础

表达式由运算对象和运算符组成，其核心特性包括类型一致性、左值右值区分、优先级与结合律，以及求值顺序。

4.1.1 核心概念

1. 运算对象类型要求

  • 二元运算符（如+、*）通常要求运算对象类型相同；若不同，需通过隐式类型转换统一（如小整型提升为int）。

  • 类类型对象可通过重载运算符自定义运算规则（如string的+用于拼接，<<用于输出）。

2. 左值与右值

C++ 中所有表达式要么是左值（lvalue），要么是右值（rvalue），核心区别在于是否代表 “内存中的身份”：

类型核心含义使用场景关键规则
左值代表对象的内存位置（身份）赋值运算符左侧、取地址符&操作数左值可代替右值使用（如int a=5; int b=a;）
右值代表对象的值（内容）赋值运算符右侧、函数返回值右值不可代替左值（如5=a;非法）
  • 特殊场景：decltype作用于左值表达式（非变量）时，返回引用类型。例如：
int a=10;

decltype(++a) b=a;  // ++a是左值表达式，b的类型为int&

decltype(a++) c=a;  // a++是右值表达式，c的类型为int

4.1.2 优先级与结合律

  • 优先级：决定不同运算符的执行顺序（如*优先级高于+，3+4*5先算4*5）。

  • 结合律：决定同一优先级运算符的组合顺序：

    • 左结合律（多数二元运算符）：从左向右组合（如a-b-c等价于(a-b)-c）。

    • 右结合律（仅赋值、条件等少数运算符）：从右向左组合（如a=b=c等价于a=(b=c)）。

4.1.3 求值顺序

  • 复合表达式（如cout << i << ++i）中，运算对象的求值顺序不固定，可能导致未定义行为（无法确定先算i还是++i）。

  • 仅 4 种运算符明确规定求值顺序：

运算符求值顺序用途示例
逻辑与&&先左后右，左假则右不执行if (a>0 && b/a>2)（避免除零）
逻辑或 ``
条件运算符?:先算条件，再算对应分支grade>60 ? "pass" : "fail"
逗号运算符,先左后右，返回右值结果for (int i=0,j=10; i<j; i++,j--)
  • 建议：

  1. 不确定优先级时用括号明确顺序（如(a+b)*c）。

  2. 若修改某运算对象的值（如++i），同一表达式中不再使用该对象。

4.2 算术运算符

处理数值计算，按优先级从高到低分为 3 组，运算对象均为算术类型。

运算符名称优先级结合律关键规则示例
+（单目）正号1（最高）右结合不改变运算对象值+3（结果为 3）
-（单目）负号1右结合对运算对象取反-3（结果为 - 3）
*乘法2左结合正常数值乘法3*4（结果为 12）
/除法2左结合整数除法向零舍入（如7/2=3，-7/2=-3）10/3（结果为 3）
%求余2左结合运算对象必须为整数，结果与被除数同号10%3=1，-10%3=-1
+（双目）加法3左结合正常数值加法3+4（结果为 7）
-（双目）减法3左结合正常数值减法7-2（结果为 5）

4.3 逻辑和关系运算符

用于判断条件，求值结果均为bool类型（true或false）。

4.3.1 关系运算符

比较运算对象的大小或相等性，优先级高于逻辑运算符：

运算符名称优先级结合律示例
<小于1左结合3<5（true）
<=小于等于1左结合5<=5（true）
>大于1左结合3>5（false）
>=大于等于1左结合5>=6（false）
==等于2左结合3==5（false）
!=不等于2左结合3!=5（true）

4.3.2 逻辑运算符

判断条件的逻辑关系，支持 “短路求值”：

运算符名称优先级结合律短路规则示例
!逻辑非1（高）右结合对运算对象取反（非bool先转bool）!0（true）
&&逻辑与2左结合左假则右不执行(a>0)&&(b/a>2)
``逻辑或3（低）左结合
  • 注意：避免用算术值与bool直接比较。例如：
int a=5;

if(a)          // 正确：a非0，隐式转为true

if(a==true)    // 错误：true转int为1，5==1为false

4.4 赋值运算符

用于给左值赋值，支持普通赋值和复合赋值，核心特性为 “右结合律” 和 “左值要求”。

4.4.1 普通赋值

  • 语法：左值 = 右值，右值可是表达式、字面值或初始化列表（C++11）。

  • 规则：

  1. 左值必须是可修改的左值（如const int a=5; a=10;非法）。

  2. 右值类型与左值不同时，会隐式转换为左值类型（如int a=3.14;，3.14转int为 3）。

  3. 赋值表达式的结果是左值（支持链式赋值）：

int a,b,c;

a=b=c=10;  // 等价于a=(b=(c=10))，均赋值为10

4.4.2 复合赋值运算符

将 “运算 + 赋值” 合并，共 10 种，核心优势是仅求值一次（普通赋值需求值两次）：

运算符等价表达式适用类型
+=a = a + b算术类型、string 等
-=a = a - b算术类型
*=a = a * b算术类型
/=a = a / b算术类型
%=a = a % b整数类型
<<=a = a << b整数类型（位运算）
>>=a = a >> b整数类型（位运算）
&=a = a & b整数类型（位运算）
^=a = a ^ b整数类型（位运算）
`=``a = a
  • 示例：a+=3等价于a=a+3，但a仅求值一次（对复杂表达式如vec[i]更高效）。

4.5 递增和递减运算符

用于对运算对象 “加 1” 或 “减 1”，分前置版本（++a/--a）和后置版本（a++/a--），核心区别在于返回值。

版本执行顺序返回值类型效率适用场景
前置（++a）先加 1，再返回修改后的对象左值（对象本身）高无需保留原始值（如循环递增）
后置（a++）先返回原始值副本，再加 1右值（副本）低需保留原始值（如cout<<a++）

  • 关键建议：如无必要，优先使用前置版本。后置版本需额外保存原始值副本，对迭代器等复杂类型消耗较大。

  • 经典场景：结合解引用遍历容器（递增运算符优先级高于解引用）：

vector\<int> vec={1,2,3};

auto p=vec.begin();

while(p!=vec.end()){

&#x20;   cout<<\*p++<\<endl;  // 先解引用原始值，再递增指针（高效简洁）

}

4.6 成员访问运算符

用于访问类或结构体的成员，共两种，适用于不同对象类型：

运算符语法适用对象等价转换
点运算符.obj.mem对象（或引用）无
箭头运算符->ptr->mem指针等价于(*ptr).mem（注意括号）
  • 示例：
struct Person{ string name; int age; };

Person p={"Alice",20};

Person\* ptr=\&p;

cout<\<p.name;    // 点运算符：访问对象p的name成员

cout<\<ptr->age;  // 箭头运算符：访问指针ptr指向对象的age成员

cout<<(\*ptr).name;// 等价于ptr->name

4.7 条件运算符

三元运算符，语法为cond ? expr1 : expr2，用于简化 “二选一” 逻辑。

  • 执行规则：先判断cond，若为true则执行expr1，否则执行expr2，结果为对应表达式的值。

  • 嵌套使用：支持多层嵌套（建议不超过 2 层，避免可读性下降）：

int grade=75;

string res=grade>90?"high pass":(grade<60?"fail":"pass");

// 结果为"pass"
  • 优先级提醒：条件运算符优先级极低，需加括号避免歧义。例如：
cout<<(grade>60?"pass":"fail");  // 正确：先算条件，再输出结果

cout<\<grade>60?"pass":"fail";    // 错误：等价于(cout<\<grade)>60?...

4.8 位运算符

作用于整数类型的二进制位，共 6 种，需注意 “符号位处理” 和 “可移植性”。

4.8.1 位运算符分类

运算符名称作用示例（假设a=0b1010，b=0b0110）
~位求反对每一位取反（0 变 1，1 变 0）~a=0b0101（注意符号位扩展）
&位与同 1 则 1，否则 0a&b=0b0010
``位或有 1 则 1，否则 0
^位异或不同则 1，相同则 0a^b=0b1100
<<左移向左移动 n 位，右侧补 0，左侧超出舍弃a<<2=0b101000
>>右移无符号数：左侧补 0；有符号数：补符号位（依赖机器）a>>1=0b0101（假设a为 unsigned）

4.8.2 关键注意事项

  1. 小整型提升：char、short等小整型会先提升为int再运算。

  2. 符号位风险：带符号整数的位运算结果依赖机器（如-1>>1，部分机器得-1，部分得0x7FFFFFFF），建议仅用于无符号类型。

  3. 移位位数限制：移动位数必须小于运算对象的位数（如int a=5; a<<32;非法，未定义行为）。

  4. 重载版本：标准 IO 的<<和>>是位运算符的重载，用于输入输出，与位运算无关。

4.9 sizeof 运算符

用于计算 “表达式结果类型” 或 “类型” 所占的字节数，返回size_t类型（无符号整数）。

4.9.1 语法与规则

语法形式作用示例结果说明（64 位系统）
sizeof(type)计算类型type的字节数sizeof(int)4
sizeof expr计算表达式expr结果类型的字节数sizeof(3.14)8（double类型）

4.9.2 特殊场景

  1. 数组：sizeof(arr)返回整个数组的字节数，不将数组转为指针。例如：
int arr\[5]={1,2,3,4,5};

cout<\<sizeof(arr);  // 结果为20（5\*4）

cout<\<sizeof(arr\[0]);// 结果为4（单个int）

// 计算数组元素个数：sizeof(arr)/sizeof(arr\[0]) → 5
  1. 指针：sizeof(ptr)返回指针类型的字节数（64 位系统为 8，32 位为 4），与指向的对象无关（如int* p=arr; sizeof(p)结果为 8，与arr数组大小无关）。

3. 类对象：sizeof(string)或sizeof(vector<int>)仅返回对象 “固定部分” 的字节数（如指针、大小计数器），不包含对象存储的元素占用空间（如string的字符数据、vector的元素数组）。

4.10 逗号运算符

逗号运算符（,）是优先级最低的运算符，用于将多个表达式串联成一个表达式，核心特性是 “先左后右求值，返回右表达式结果”。

4.10.1 语法与规则

  • 语法：expr1, expr2，先执行expr1（结果丢弃），再执行expr2，最终返回expr2的值。

  • 结合律：左结合律，多个逗号运算符从左向右依次执行（如expr1, expr2, expr3等价于((expr1, expr2), expr3)）。

4.10.2 典型使用场景

  1. for 循环初始化与迭代：在for循环头中，用逗号分隔多个初始化语句或迭代操作，简化代码结构：
// 初始化i=0、j=10，每次迭代i递增、j递减

for (int i=0, j=10; i\<j; ++i, --j) {

&#x20;   cout << "i=" << i << ", j=" << j << endl;

}
  1. 简化多条表达式为一条：在语法要求 “单个表达式” 的场景（如if条件、赋值语句），用逗号运算符整合多条操作：
int a=0, b=0;

// 先执行a++，再执行b++，最终返回b++的值（0，执行后b=1）

int res = (a++, b++); &#x20;

cout << res;  // 输出0

4.10.3 注意事项

  • 括号优先级：逗号运算符优先级极低，若需优先执行逗号表达式，需用括号包裹，避免与其他运算符混淆：
// 错误：等价于(int res=a++), b++; res仅接收a++的值（0）

int res = a++, b++; &#x20;

// 正确：先执行a++，再执行b++，res接收b++的值（0）

int res = (a++, b++); &#x20;
  • 避免滥用：不要在条件判断（如if、while）中用逗号运算符串联无关逻辑，会降低代码可读性。例如：
// 不推荐：逻辑混乱，难以理解条件核心是b>0

if (a++, b>0) { ... } &#x20;

// 推荐：拆分逻辑，明确条件意图

a++;

if (b>0) { ... } &#x20;

4.11 类型转换

C++ 中，当运算对象类型不匹配或场景需要时，会自动或手动将一种类型转换为另一种类型，分为隐式类型转换（编译器自动完成）和显式类型转换（手动指定转换方式）。

4.11.1 隐式类型转换

隐式类型转换由编译器自动触发，无需程序员干预，常见场景如下：

转换场景转换规则示例
小整型提升bool、char、short等小整型转为int（若int能容纳），否则转为unsigned intchar c='a'; int i=c;（'a'的 ASCII 值 97 转为int）
条件中的非bool转bool零值（0、0.0、nullptr、空字符串）转为false，非零值转为trueif (5)（5 转为true）；if (0.0)（0.0 转为false）
初始化与赋值初始值 / 右值转为变量 / 左值的类型int a=3.14;（3.14 转为int 3）；double d=5;（5 转为double 5.0）
算术 / 关系运算类型统一不同类型运算对象转为 “更宽” 的类型（避免精度损失），称为 “常用算术转换”3 + 3.14（3 转为double 3.0，结果为 6.14）
数组转指针多数情况下，数组名自动转为指向首元素的指针（sizeof、&、decltype等场景除外）int arr[5]; int* p=arr;（arr转为int*，指向arr[0]）
指针转换0或nullptr转为任意指针类型；非const指针转为void*；任意对象指针转为const void*void* vp=arr;（int*转为void*）；const void* cvp=&a;（int*转为const void*）
类类型自定义转换类通过构造函数或转换函数定义的隐式转换规则string s="hello";（C 风格字符串转为string）；while (cin>>s)（cin转为bool，判断输入是否成功）

常用算术转换细节

当算术运算（如+、*）的运算对象类型不同时，按以下优先级转换（从低到高，优先转为更高优先级类型）：

  1. long double

  2. double

  3. float

  4. unsigned long long

  5. long long

  6. unsigned long

  7. long

  8. unsigned int

  9. int

  • 示例：int i=5; long long ll=10; i+ll（i转为long long，结果为long long类型）。

  • 无符号与有符号类型转换规则：

    • 若无符号类型的 “宽度” 不小于有符号类型（如unsigned int与int，均为 4 字节），则有符号类型转为无符号类型。

    • 若无符号类型的 “宽度” 小于有符号类型（如unsigned short与int），则两者均转为有符号类型（int）。

    • 注意：无符号与有符号类型运算可能导致意外结果，如unsigned int u=1; int i=-2; if (i<u)（i转为unsigned int，-2 对应极大的无符号值，条件为false）。

4.11.2 显式类型转换（强制类型转换）

当隐式类型转换无法满足需求（如将double转为int需截断小数），或需明确告知编译器转换意图时，使用显式类型转换。C++ 提供 4 种标准显式转换方式，避免旧式转换的歧义与风险。

1. static_cast：静态类型转换（最常用）

  • 适用场景：非const类型的 “安全转换”，如基本类型转换、父类与子类指针 / 引用的上行转换（子类→父类，安全）、void 指针与其他指针的转换。

  • 规则：编译时检查转换合法性，不支持去除const属性；若转换可能存在风险（如double转int精度损失），编译器不报错，但需程序员自行承担责任。

  • 示例：

double d=3.14;

int i=static\_cast\<int>(d);  // 合法：3.14截断为3

int\* p=static\_cast\<int\*>(malloc(sizeof(int)));  // 合法：void\*转为int\*

2. const_cast：常量性转换（仅用于修改 const 属性）

  • 适用场景：唯一能修改表达式 “底层const” 的转换方式，即去除或添加变量的const/volatile属性（仅适用于指针或引用）。

  • 规则：仅修改const属性，不改变类型；若转换后修改了原本const变量的值，会导致未定义行为（如const int a=5; int& r=const_cast<int&>(a); r=10;，a的值可能仍为 5，因编译器可能优化为常量）。

  • 示例（合法场景：函数重载中匹配const版本）：

void print(const string& s) { cout << s; }

void print(string& s) { s+="!"; cout << s; }

string s="hello";

const string& cs=s;

// 需调用非const版本，用const\_cast去除cs的const属性

print(const\_cast\<string&>(cs)); &#x20;

3. dynamic_cast：动态类型转换（仅用于多态类）

  • 适用场景：在继承层次中，将父类指针 / 引用转为子类指针 / 引用（下行转换），或在多继承中转换为其他基类指针 / 引用（交叉转换）。

  • 规则：

    • 仅适用于包含虚函数的类（多态类），因需通过虚函数表判断对象的实际类型。

    • 转换指针时，若类型不匹配，返回nullptr；转换引用时，若类型不匹配，抛出bad_cast异常（需包含<typeinfo>头文件）。

  • 示例：

class Base { virtual void f() {} };  // 多态类（含虚函数）

class Derived : public Base {};

Base\* b=new Derived;

// 下行转换：Base\*转为Derived\*，因b实际指向Derived对象，转换成功

Derived\* d=dynamic\_cast\<Derived\*>(b); &#x20;

if (d) {  // 检查转换是否成功

&#x20;   cout << "转换成功";

}

4. reinterpret_cast：重新解释转换（最危险，不推荐）

  • 适用场景：将一种类型的指针 / 引用 “强制解释” 为另一种类型的指针 / 引用，完全依赖机器底层内存布局，不进行类型检查。

  • 规则：转换结果依赖编译器和硬件，无移植性；可能导致严重的未定义行为（如访问非法内存），仅在极低层操作（如硬件寄存器访问）中使用。

  • 示例（不推荐，仅作演示）：

int i=0x12345678;

// 将int\*转为char\*，仅访问i的第一个字节（依赖字节序，小端机器为0x78）

char\* c=reinterpret\_cast\<char\*>(\&i); &#x20;

旧式显式转换（不推荐）

C++ 兼容 C 语言的旧式显式转换，语法有两种：

  • (type)expr（如(int)3.14）

  • type(expr)（如int(3.14)）

  • 缺点：无法区分转换类型（如无法判断是static_cast还是const_cast），可读性差，错误难以追踪，建议优先使用 C++ 标准转换方式。
