第 5 章 语句

约 2591 字大约 9 分钟

5.1 简单语句

C++ 中的语句是程序执行的基本单元，按功能可分为表达式语句、空语句和复合语句。

表达式语句

表达式语句由表达式后接分号构成，执行表达式并丢弃结果（除非表达式有副作用，如输出、赋值等）。

  • 示例：
    ival + 3;        // 无实际作用（仅计算，无副作用）
cout << ival;    // 有作用（输出 ival 的值，副作用明显）
ival = 10;       // 有作用（修改 ival 的值）

空语句

空语句仅包含一个分号（;），用于语法上需要语句但逻辑上无需操作的场景。

  • 用途：如循环条件已包含所有逻辑时，循环体可简化为空语句。
  • 示例：
    // 读取输入直到遇到文件结束符，循环体为空语句
while (cin >> ival);  // 注意分号是循环体，建议添加注释说明
  • 注意：使用空语句时应添加注释，避免被误认为是笔误。

复合语句（块）

复合语句（简称“块”）是用花括号 {} 括起的语句和声明序列，自身构成一个作用域（内部声明的变量仅在块内可见）。

  • 特性：块的结尾无需分号；空块（{}）等价于空语句。
  • 示例：
    {
    int a = 10;  // 仅在当前块内可见
    cout << a;
}  // 块结束，a 销毁

5.2 语句作用域

在条件语句（if、switch）、循环语句（while、for）的控制结构内定义的变量，其作用域仅限于该语句内部。

  • 示例：
    if (int i = get_value()) {  // i 的作用域仅限于 if 语句
    cout << i;
} else {
    cout << 0;  // 仍可访问 i（if-else 共享同一作用域）
}
// 此处无法访问 i（已超出作用域）
  • 优势：限制变量作用域，避免命名冲突，提高代码可读性。

5.3 条件语句

条件语句根据条件判断执行不同分支，包括 if 语句和 switch 语句。

5.3.1 if 语句

if 语句有两种形式：带 else 分支和不带 else 分支。

  • 基本语法：
    // 形式1：无 else
if (condition) {
    statement;  // condition 为真时执行
}

// 形式2：有 else
if (condition) {
    statement1;  // condition 为真时执行
} else {
    statement2;  // condition 为假时执行
}
  • else 匹配规则：else 与离它最近的未匹配 if 绑定（避免歧义需显式使用花括号）。
    • 反例（易混淆）：
      if (a > b)
    if (b > c) cout << "a > b > c";
else  // 实际与内层 if 匹配，而非外层
    cout << "a <= b";
    • 正例（显式花括号）：
      if (a > b) {
    if (b > c) cout << "a > b > c";
} else {  // 明确与外层 if 匹配
    cout << "a <= b";
}
  • 建议：所有 if 和 else 分支均用花括号包裹，即使只有一条语句。

5.3.2 switch 语句

switch 语句根据整型表达式的值从多个分支中选择执行路径，分支由 case 标签标识。

  • 基本语法：
    switch (expression) {  // expression 必须是整型（包括字符、枚举等）
    case constant1:    // case 标签必须是整型常量表达式
        statements1;
        break;         // 跳出 switch 语句
    case constant2:
        statements2;
        break;
    default:           // 所有 case 不匹配时执行
        statements_default;
}
  • 关键特性：
    1. 穿透性：若 case 分支无 break，程序会从匹配的 case 开始，依次执行后续所有分支（包括其他 case），直至遇到 break 或 switch 结束。
      • 示例（共享逻辑）：
        switch (ch) {
    case 'a':
    case 'e':  // 'a' 或 'e' 均执行此分支
    case 'i':
    case 'o':
    case 'u':
        ++vowelCnt;
        break;
    default:
        ++otherCnt;
}
    2. case 标签作用域：case 标签本身不引入新作用域，若在 case 分支内定义变量，需用块 {} 限制作用域（避免跨分支访问未初始化变量）。
      • 示例：
        switch (i) {
    case 0: {
        int x = 10;  // 块内定义，仅在 case 0 可见
        cout << x;
        break;
    }
    case 1:
        // 此处无法访问 x，避免错误
        break;
}
    3. default 标签：建议始终定义 default 分支（即使为空），确保所有情况都有处理，增强代码健壮性。

5.4 迭代语句

迭代语句用于重复执行一段代码，包括 while、for（含范围 for）和 do while 三种。

5.4.1 while 语句

while 语句先判断条件，条件为真时执行循环体，适合循环次数不确定的场景。

  • 语法：
    while (condition) {  // condition 可为表达式或带初始化的变量声明
    statement;
}
  • 示例：
    // 读取输入直到遇到非数字
int val;
while (cin >> val) {  // 输入成功时条件为真
    sum += val;
}
  • 注意：循环条件或体内定义的变量，每次迭代都会重新创建和销毁。

5.4.2 传统 for 语句

for 语句通过初始化、条件判断和迭代操作控制循环，适合循环次数已知的场景。

  • 语法：
    for (init-statement; condition; expression) {
    statement;
}
    • init-statement：初始化语句（可声明变量、赋值等，仅执行一次）。
    • condition：循环条件（为真时执行循环体）。
    • expression：迭代操作（每次循环体执行后执行）。
  • 变体形式：
    1. 省略部分组件：
      for (int i = 0; ; ++i) { ... }  // 省略 condition，等价于条件恒为真（无限循环）
for (;;) { ... }                // 省略所有组件，无限循环
    2. 多变量初始化（仅支持一条声明语句）：
      for (int i = 0, j = 10; i < j; ++i, --j) { ... }  // 同时初始化 i 和 j

5.4.3 范围 for 语句

范围 for 语句简化容器或序列的遍历，自动迭代所有元素。

  • 语法：
    for (declaration : expression) {  // expression 为容器或序列（如 vector、string）
    statement;
}
  • 特性：
    1. declaration 定义循环变量，类型需与序列元素兼容（建议用 auto 自动推导）。
    2. 若需修改元素，循环变量必须声明为引用类型（如 auto &x : vec）。
    3. 循环过程中不能修改序列大小（如 push_back 或 erase），否则预存的 end() 迭代器会失效。
  • 示例：
    vector<int> vec = {1, 2, 3, 4};
for (auto x : vec) {        // 只读遍历
    cout << x << " ";
}
for (auto &x : vec) {       // 修改元素（引用类型）
    x *= 2;
}

5.4.4 do while 语句

do while 语句先执行循环体，再判断条件，至少执行一次循环，适合循环体必须先执行的场景。

  • 语法：
    do {
    statement;
} while (condition);  // 注意末尾的分号
  • 注意：condition 中使用的变量需定义在循环体外（因循环体先执行）。
  • 示例：
    int val;
do {
    cin >> val;
    sum += val;
} while (val != 0);  // 输入 0 时终止循环（至少执行一次输入）

5.5 跳转语句

跳转语句改变程序执行流程，包括 break、continue、goto 和 return（return 详见函数章节）。

5.5.1 break 语句

break 语句终止最近的循环（while、for、do while）或switch 语句，并跳转到语句后的第一条语句。

  • 示例：
    for (int i = 0; i < 10; ++i) {
    if (i == 5) break;  // 当 i=5 时，终止 for 循环
    cout << i;
}
// 输出：01234
  • 限制：仅能用于循环或 switch 内部。

5.5.2 continue 语句

continue 语句终止循环的当前迭代，直接进入下一次迭代（仅适用于循环语句）。

  • 示例：
    for (int i = 0; i < 10; ++i) {
    if (i % 2 == 0) continue;  // 偶数时跳过当前迭代
    cout << i;
}
// 输出：13579
  • 与 break 区别：continue 仅跳过当前迭代，break 终止整个循环。

5.5.3 goto 语句

goto 语句无条件跳转到同一函数内的标签语句，但会破坏程序结构，不推荐使用。

  • 语法：
    label: statement;  // 标签语句（label 为标识符，后接冒号）
goto label;        // 跳转到 label 处
  • 风险：
    1. 跳转可能跳过变量初始化，导致未定义行为。
    2. 使程序流程混乱，难以理解和维护。
  • 例外场景：在嵌套循环中快速跳出多层循环（需谨慎使用）。

5.6 try 语句块和异常处理

异常处理机制用于处理程序运行时的反常情况（如输入错误、内存不足等），核心组件包括 throw 表达式、try 语句块和异常类。

5.6.1 throw 表达式

throw 表达式用于引发异常，格式为 throw 表达式;，表达式类型决定异常类型。

  • 示例：
    if (a != b) {
    // 抛出 runtime_error 类型异常，附带错误信息
    throw runtime_error("a and b must be equal");
}
  • 说明：抛出异常后，程序终止当前执行路径，寻找匹配的异常处理器。

5.6.2 try 语句块

try 语句块用于捕获并处理异常，由 try 块和后续的一个或多个 catch 子句组成。

  • 语法：
    try {
    // 可能引发异常的代码
    statement;
} catch (exception_type1 e1) {  // 捕获 exception_type1 类型异常
    // 处理逻辑
} catch (exception_type2 e2) {  // 捕获 exception_type2 类型异常
    // 处理逻辑
} catch (...) {  // 捕获所有类型异常（通常作为最后一个子句）
    // 通用处理逻辑
}
  • 执行流程：
    1. 若 try 块中无异常，跳过所有 catch 子句，执行后续代码。
    2. 若 try 块中抛出异常，编译器依次匹配 catch 子句的异常类型，执行首个匹配的子句。
    3. 若未找到匹配的 catch 子句，程序调用 terminate 函数终止执行。
  • 示例：
    try {
    if (a != b) throw runtime_error("mismatch");
} catch (runtime_error err) {  // 匹配 runtime_error 类型异常
    cout << err.what() << endl;  // what() 返回异常信息
    // 处理后继续执行后续代码
}

5.6.3 标准异常

C++ 标准库定义了一组异常类，用于报告常见错误，分为四大类，定义在不同头文件中：

头文件异常类用途说明
<exception>exception所有标准异常的基类，仅报告异常发生
<new>bad_alloc动态内存分配失败时抛出（如 new 失败）
<typeinfo>bad_cast类型转换失败时抛出（如 dynamic_cast 错误）
<stdexcept>runtime_error运行时检测到的错误（如参数越界）
<stdexcept>logic_error程序逻辑错误（如无效参数）

  • 继承关系：exception 是基类，runtime_error 和 logic_error 是其子类，各自派生更具体的异常（如 out_of_range 继承自 logic_error）。

  • 使用规范：

    • stdexcept 中的异常类（如 runtime_error）需用字符串初始化（提供错误信息）。
    • 其他异常类（如 bad_alloc）只能默认初始化，无自定义信息。
    • 异常对象的 what() 成员函数返回错误描述（C 风格字符串）。

  • 示例（使用 out_of_range）：

    void check(size_t i, size_t size) {
    if (i >= size) {
        throw out_of_range("index out of bounds");  // 抛出逻辑错误
    }
}

异常处理的核心是分离异常检测与处理，但需注意异常安全（如资源释放、对象状态一致性），这是设计健壮程序的重要挑战。
