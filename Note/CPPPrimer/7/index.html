第 7 章 类的深入理解与应用

约 2259 字大约 8 分钟

2025-09-26

7.0 核心概念与积累总结

7.0.0 类的 const 成员函数

const 成员函数的核心特性是不会修改类的数据成员，其声明和定义需同时携带 const 关键字：

class Student {
public:
    int age() const;  // 类内声明
};

int Student::age() const {  // 类外定义
    // 函数体中不能修改成员变量
    return m_age;
}

注意：const 成员函数只能且只能调用本类的 const 成员函数，不能调用非 const 成员函数。

7.0.1 类的 private 成员访问特性

类的成员函数可以访问同类型其他实例的私有成员，例如：

class Student {
private:
    int m_age;
public:
    bool isSameAge(const Student& other) {
        return m_age == other.m_age;  // 合法访问同类型对象的私有成员
    }
};

7.1 抽象数据类型（ADT）的定义

7.1.1 类的设计原则

设计类接口时应遵循封装原则：用户使用类时无需关注其实现细节，只需关注接口功能。

7.1.2 类成员函数的隐式 inline 特性

定义在类内部的函数会被隐式声明为 inline 函数，例如：

class SalesData {
public:
    double calculatePrice() {  // 隐式 inline
        return m_price * m_quantity;
    }
};

7.1.4 构造函数基础

  • 构造函数无返回类型，与类同名
  • 用于初始化对象数据成员，对象创建时自动调用
  • 支持重载（重载）
  • 若未定义任何构造函数，编译器会生成默认构造函数（功能有限，建议显式定义）

7.1.5 对象的拷贝、赋值与析构

  • 编译器会自动合成默认默认版本的拷贝构造、赋值运算符和析构函数
  • 管理动态内存的类必须显式定义这些函数，否则能依赖默认版本

7.2 访问控制与封装机制

class 与 struct 的区别

唯一区别是默认访问权限：

  • class：默认 private
  • struct：默认 public（适合所有成员需公开的场景）

7.2.1 友元机制

友元用于打破封装，允许外部函数或类访问私有成员：

class SalesData {
    // 友元声明（不受访问控制符限制）
    friend double calculateDiscount(const SalesData&);
private:
    double m_price;
};

// 友元函数类外定义（需提前声明）
double calculateDiscount(const SalesData& data) {
    return data.m_price * 0.9;  // 可访问私有成员
}

友元规则：

  • 声明仅指定访问权限，需在类外单独声明函数
  • 友元关系不具传递性
  • 重载函数需分别声明为友元

7.3 类的高级特性

7.3.1 类成员进阶

类型成员定义

类内可定义类型别名，需遵循先定义后使用原则：

class TextBook {
public:
    using PageNum = size_t;  // 类型成员
    PageNum getTotalPages() { return m_totalPages; }
private:
    PageNum m_totalPages;
};

默认构造函数显式声明

定义了其他构造函数后，需显式声明默认构造函数：

class Student {
public:
    Student(string name) : m_name(name) {}
    Student() = default;  // 显式默认构造函数
private:
    string m_name;
};

类内初始值

成员变量可在声明时初始化，构造函数初始化列表可省略这些成员：

class Product {
private:
    string m_id = "unknown";  // 类内初始值
    double m_price{0.0};      // 支持花括号初始化
};

内联成员函数

四种实现方式：

  1. 类内定义（隐式 inline）
  2. 类内显式声明 inline
  3. 类外定义时加 inline
  4. 类内声明且类外定义均加 inline

注意：inline 函数需与类定义在同一头文件

可变数据成员

mutable 关键字允许 const 成员函数修改该成员：

class Counter {
private:
    mutable int m_accessCount = 0;  // 可变成员
public:
    int getValue() const {
        m_accessCount++;  // const 函数中可修改
        return m_value;
    }
private:
    int m_value;
};

7.3.2 返回 *this 的成员函数

通过返回对象引用实现链式操作：

class Calculator {
private:
    int m_result;
public:
    Calculator& add(int num) {
        m_result += num;
        return *this;  // 返回对象本身的引用
    }
    Calculator& multiply(int num) {
        m_result *= num;
        return *this;
    }
};

// 使用示例
Calculator calc;
calc.add(5).multiply(3);  // 链式调用

7.3.3 类类型特性

  • 类不能包含自身类型的成员，但可包含自身类型的指针或引用
  • 类定义后即形成完整类型

7.4 类的作用域

成员函数返回类型为类成员时的处理

需显式指定类作用域：

class Student {
public:
    enum Grade { A, B, C, D };
    Grade getGrade() const;
};

// 类外定义时需指定返回类型的作用域
Student::Grade Student::getGrade() const {
    return A;
}

7.4.1 类的名字查找规则

  1. 先编译所有成员声明
  2. 再编译成员函数体（函数体内可使用类的所有成员）
  3. 类内类型名需放在开头，否则后续成员不可见

7.5 构造函数深入解析

7.5.1 构造函数初始值列表

推荐使用初始值列表初始化成员，而非函数体内赋值：

class Date {
private:
    int m_year;
    int m_month;
    int m_day;
public:
    // 初始值列表初始化（推荐）
    Date(int year, int month, int day) 
        : m_year(year), m_month(month), m_day(day) {}
};

特殊规则：

  • const 成员、引用成员必须在初始值列表中初始化
  • 成员初始化顺序与类中声明顺序一致，与初始值列表顺序无关

7.5.2 委托构造函数

简化构造函数代码，通过调用其他构造函数完成初始化：

class Student {
private:
    string m_name;
    int m_age;
public:
    // 目标构造函数
    Student(string name, int age) : m_name(name), m_age(age) {}
    
    // 委托构造函数
    Student() : Student("unknown", 0) {}
    Student(string name) : Student(name, 0) {}
};

7.5.4 类类型转换

转换构造函数

单参数构造函数定义隐式转换规则：

class SalesData {
public:
    SalesData(const string& book) : m_bookNo(book) {}  // 转换构造函数
private:
    string m_bookNo;
};

// 隐式转换：string -> SalesData
string book = "12345";
SalesData data = book;  // 合法（未声明 explicit 时）

抑制隐式转换（explicit）

class SalesData {
public:
    explicit SalesData(const string& book) : m_bookNo(book) {}
};

SalesData data1("12345");  // 直接初始化（合法）
SalesData data2 = "12345"; // 拷贝初始化（非法）

// 显式转换（合法）
SalesData data3 = static_cast<SalesData>("12345");

7.5.5 聚合类

满足以下条件的类可使用花括号初始化：

  1. 所有成员为 public
  2. 无用户定义的构造函数
  3. 无类内初始值
  4. 无基类和虚函数
struct Point {  // 聚合类
    int x;
    int y;
};

Point p = {10, 20};  // 合法初始化

7.5.6 字面值常量类

可在常量表达式中使用的类，满足：

  1. 数据成员均为字面值类型
  2. 含 constexpr 构造函数
  3. 类内初始值为常量表达式
  4. 使用默认析构函数

constexpr 构造函数示例：

class Debug {
public:
    constexpr Debug(bool flag) : m_enabled(flag) {}  // constexpr 构造函数
private:
    bool m_enabled;
};

constexpr Debug debug(true);  // 编译期初始化

7.6 类的静态成员

静态成员与类关联，而非与对象关联：

class Account {
public:
    static double getInterestRate() {  // 静态成员函数
        return s_interestRate;
    }
    static void setInterestRate(double rate) {
        s_interestRate = rate;
    }
private:
    static double s_interestRate;  // 静态数据成员声明
};

// 静态数据成员类外定义
double Account::s_interestRate = 0.05;

特性：

  • 静态成员函数无 this 指针，不能声明为 const
  • 可通过类名直接访问（Account::getInterestRate()）
  • 静态数据成员需在类外定义（constexpr 类型除外）
  • 可作为类的不完全类型（如自身类类型的静态成员）
  • 可作为函数默认实参## 7.6 类的静态成员（补充细节）

7.6.1 静态成员的特殊使用场景

1. 静态成员作为不完全类型

静态数据成员的类型可以是其所属的类类型（普通成员不行），适用于实现链表、树等数据结构：

class Node {
public:
    int data;
    static Node* head;  // 静态成员：类型为自身类指针（不完全类型合法）
    Node* next;         // 普通成员：仅允许指针/引用，不能是Node类型
};

// 类外定义静态成员
Node* Node::head = nullptr;

2. 静态成员作为默认实参

普通成员不能作为默认实参（依赖对象实例），但静态成员可以（属于类，不依赖对象）：

class Order {
public:
    static double taxRate;  // 静态成员：税率
    // 静态成员作为默认实参
    double calculateTotal(double price, double tax = taxRate) {
        return price * (1 + tax);
    }
};

// 类外初始化静态成员
double Order::Order::taxRate = 0.1;

// 使用示例
Order order;
order.calculateTotal(100);        // 用默认税率0.1，结果110
order.calculateTotal(100, 0.05);  // 自定义税率0.05，结果105

7.6.2 静态成员的初始化与访问

1. 初始化规则

静态成员类型初始化位置示例
非constexpr类型类外定义时初始化（仅一次）double Account::s_interestRate = 0.05;
constexpr类型类内初始化（可选），仍需类外声明class A { public: constexpr static int num = 10; }; constexpr int A::num;
静态成员函数类内声明，类外定义（不加static）class A { public: static void func(); }; void A::func() { ... }

2. 访问方式

静态成员可通过类名或对象访问，推荐用类名（更清晰）：

class Account {
public:
    static double s_interestRate;
    static void setRate(double rate) { s_interestRate = rate; }
};

// 访问方式1：类名 + 作用域运算符（推荐）
Account::setRate(0.06);
cout << Account::s_interestRate;  // 输出0.06

// 访问方式2：对象（不推荐，易误解为依赖对象）
Account acc;
acc.setRate(0.07);
cout << acc.s_interestRate;       // 输出0.07
