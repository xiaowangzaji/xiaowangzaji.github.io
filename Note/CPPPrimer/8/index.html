第 8 章 输入输出流（IO流）

约 1961 字大约 7 分钟

2025-09-26

8.1 IO类体系

IO库通过类层次结构实现对不同设备（控制台、文件、内存字符串）的输入输出操作，核心类型分布在三个头文件中：

头文件功能描述核心类型（窄字符/宽字符）
<iostream>控制台IO操作istream/wistream（输入）、ostream/wostream（输出）、iostream/wiostream（双向）
<fstream>文件IO操作ifstream/wifstream（文件输入）、ofstream/wofstream（文件输出）、fstream/wfstream（文件双向）
<sstream>内存字符串IO操作istringstream（字符串输入）、ostringstream（字符串输出）、stringstream（字符串双向）

说明：

  • 带w前缀的类型用于处理宽字符（wchar_t），需配合宽字符相关工具（如wcin、wcout、宽字符串字面量L"示例"）。
  • 继承关系：fstream和sstream类均继承自iostream类，因此派生类对象可隐式转换为基类引用使用。
  • 所有输入流的>>操作默认以空白字符为分隔符读取"单词"。

8.1.1 IO对象的特性：不可拷贝与赋值

IO对象（如cin、ifstream）不能被拷贝或赋值，因此：

  • 函数参数或返回值必须使用引用类型
  • 引用不能是const（因IO操作会改变对象状态）
// 正确：使用非const引用传递流
void print(ostream& os) { os << "示例"; }

// 错误示例
ostream func() { return cout; } // 错误：不能返回流对象（拷贝被禁止）

8.1.2 流的条件状态

IO操作可能失败（如文件不存在、输入格式错误），需通过条件状态判断流是否可用。

状态标志
状态标志含义
goodbit无错误（值为0，流可用）
failbit可恢复错误（如输入类型不匹配），流可继续使用
badbit不可恢复错误（如系统故障），流无法再使用
eofbit已到达文件末尾（通常伴随failbit置位）
状态管理函数
函数功能描述
rdstate()返回当前状态（iostate类型，位集合）
setstate(state)保留原有状态，新增state标志位
clear()清除所有错误状态（恢复为goodbit）
clear(state)直接将状态设置为state
常用判断方式

流对象可直接作为条件判断（隐式转换为bool），等价于!fail()：

string word;
while (cin >> word) { // 读取成功则继续，失败则退出循环
    // 处理输入内容
}
状态重置示例
int num;
cin >> num;
if (cin.fail()) { // 输入非整数时failbit置位
    cerr << "输入格式错误！" << endl;
    cin.clear(); // 清除错误状态
    // 忽略缓冲区中残留的错误输入（避免死循环）
    cin.ignore(numeric_limits<streamsize>::max(), '\n');
}

8.1.3 输出缓冲区管理

输出流通过缓冲区减少IO操作次数以提升性能，缓冲区刷新（数据写入设备）的触发场景如下：

自动刷新
  • 程序正常结束（执行return）
  • 缓冲区满
  • 读写关联流（如cin读取前会刷新cout）
手动刷新
操纵符/函数功能描述
endl输出换行符并刷新缓冲区
flush仅刷新缓冲区（无换行）
ends输出空字符\0并刷新（常用于C风格字符串）
unitbuf设置流为"每次操作后自动刷新"（如cout << unitbuf;）
nounitbuf取消unitbuf设置，恢复默认缓冲机制
os.flush()成员函数，等价于flush操纵符
流关联

输入流可通过tie()关联到输出流，实现"读输入前先刷新输出"。标准库默认将cin与cout关联。

cin.tie(&cerr);   // 解除与cout的关联，改为关联cerr
cout.tie(nullptr); // 取消cout的关联

注意：程序异常终止时，缓冲区不会自动刷新，可能导致输出内容丢失。

8.2 文件输入输出

<fstream>头文件提供文件流类，用于读写磁盘文件。使用时需将流对象与文件绑定，并指定打开模式。

8.2.1 文件流的基本操作

创建与绑定文件
#include <fstream>
using namespace std;

int main() {
    // 方式1：构造时绑定文件
    ifstream in("input.txt");  // 只读打开（默认in模式）
    ofstream out("output.txt"); // 只写打开（默认out模式，会清空文件）
    
    // 方式2：先定义对象，再通过open()绑定
    fstream fs;
    fs.open("data.txt", ios::in | ios::out); // 读写模式打开
    
    // 检查打开是否成功
    if (!fs.is_open()) {
        cerr << "文件打开失败！" << endl;
        return -1;
    }
    
    fs.close(); // 关闭文件（析构时自动关闭，但建议显式关闭）
    return 0;
}
核心成员函数
  • open(filename, mode)：绑定并打开文件，失败则置位failbit
  • close()：关闭文件，释放资源（关闭后可重新绑定其他文件）
  • is_open()：判断文件是否成功打开（比!fs更直观）

8.2.2 文件打开模式

打开模式指定文件的操作方式，需用位或运算符（|）组合，且需符合流类型的限制（如ifstream不能用out模式）。

模式含义适用流类型
ios::in只读（文件必须存在）ifstream、fstream
ios::out只写（文件不存在则创建）ofstream、fstream
ios::app写操作追加到文件末尾（隐含out模式）ofstream、fstream
ios::trunc打开时清空文件内容（需配合out模式）ofstream、fstream
ios::ate打开后立即定位到文件末尾（可读写）所有文件流
ios::binary二进制模式（不转换换行符等，用于非文本文件）所有文件流

注意事项：

  • ofstream默认模式为ios::out | ios::trunc（打开即清空），如需保留文件内容，需显式指定ios::app或ios::in
  • app模式下，所有写操作均在末尾，无法修改已有内容
  • 二进制模式（ios::binary）需配合read()/write()函数

8.3 字符串流（stringstream）

<sstream>头文件提供字符串流类，用于在字符串与基本数据类型间转换，或拼接复杂字符串。

8.3.1 核心操作与用途

字符串流的核心是通过str()函数访问或设置内部字符串，配合>>/<<实现类型转换。

类用途示例场景
istringstream从字符串读取数据（字符串→基本类型）解析空格分隔的配置项
ostringstream向字符串写入数据（基本类型→字符串）拼接含多种类型的日志信息
stringstream双向操作（读写字符串）临时存储并处理混合类型数据
字符串流特有操作
操作功能描述
strm.str()返回流中保存的字符串拷贝
strm.str(s)将字符串s拷贝到流中，覆盖原有内容
使用示例

示例1：字符串转整数

#include <sstream>
#include <string>
#include <stdexcept>

int str_to_int(const string& s) {
    int num;
    istringstream iss(s); // 用字符串初始化输入流
    if (!(iss >> num)) { // 转换失败（如字符串非数字）
        throw invalid_argument("无效数字字符串");
    }
    return num;
}

示例2：拼接复杂字符串

ostringstream oss;
oss << "用户信息：" << "ID=" << 1001 << ", 姓名=" << "张三" << ", 成绩=" << 95.5;
string info = oss.str(); // info: "用户信息：ID=1001, 姓名=张三, 成绩=95.5"

注意：复用字符串流时，需先通过clear()重置状态，再用str("")清空内容：

stringstream ss;
ss << "test";
ss.clear(); // 重置错误状态（否则若之前有错误，后续操作会失败）
ss.str(""); // 清空内部字符串
ss << 123; // 正确：此时可写入新内容

8.4 流的多态使用

IO类的继承关系支持多态操作，即基类引用可接收派生类对象，统一接口的同时适配不同设备。

继承链简览：
istream ← ifstream/istringstream
ostream ← ofstream/ostringstream
iostream ← fstream/stringstream（继承自istream和ostream）

多态示例：

// 函数接收ostream基类引用，可处理cout、ofstream、ostringstream等
void log(ostream& os, const string& msg) {
    os << "[LOG] " << msg << endl;
}

int main() {
    log(cout, "控制台日志"); // 输出到控制台
    
    ofstream file_log("log.txt");
    log(file_log, "文件日志"); // 输出到文件
    
    ostringstream str_log;
    log(str_log, "字符串日志"); // 输出到内存字符串
    return 0;
}
