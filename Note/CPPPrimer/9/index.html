第 9 章 顺序容器

约 3664 字大约 12 分钟

9.1 顺序容器概述

顺序容器是标准库中用于存储线性数据的核心组件，提供动态内存管理能力，支持按顺序访问元素。不同容器在访问效率、插入/删除效率上各有侧重，需根据场景选择。

9.1.1 常用顺序容器及特性

容器类型存储结构核心特性适用场景
vector动态数组（连续）支持快速随机访问；尾部插入/删除效率高，中间插入/删除效率低需随机访问、尾部增删频繁（如存储列表数据）
deque双端队列（分段连续）支持快速随机访问；头尾插入/删除效率高，中间插入/删除效率低需头尾增删、随机访问（如实现队列、栈）
list双向链表仅支持双向顺序访问；任意位置插入/删除效率高（O(1)），内存开销大中间增删频繁（如频繁调整的列表）
forward_list单向链表仅支持单向顺序访问；任意位置插入/删除效率高，无size()操作，内存开销小单向遍历、中间增删频繁（如轻量级链表）
string动态字符数组支持快速随机访问；尾部插入/删除效率高，专为字符序列设计，提供字符串特有操作存储和处理文本（如字符串拼接、搜索）
array固定大小数组支持快速随机访问；大小固定，不可动态增删，比内置数组更安全存储固定数量的数据（如配置参数）

关键区别：

  • 连续存储（vector/deque/string/array）：随机访问效率高（O(1)），但中间增删需移动元素（O(n)）。
  • 链式存储（list/forward_list）：增删效率高（O(1)），但随机访问效率低（O(n)）。

9.1.2 容器选择原则

  1. 优先选vector：无特殊需求时，vector的综合性能最优，且支持随机访问，兼容性强。
  2. 避免滥用list：list内存开销大（需存储前驱/后继指针），仅在中间增删频繁时使用。
  3. 头尾增删选deque：需在头部和尾部同时操作时，deque效率优于vector（无需移动元素）。
  4. 固定大小选array：存储数量固定的数据时，array比内置数组更安全（支持拷贝、边界检查）。
  5. 中间增删+随机访问折中方案：
    • 若可排序：先将元素插入vector尾部，完成后排序（效率高于list）。
    • 若输入阶段增删频繁：先用list存储，输入完成后拷贝到vector（兼顾增删和访问效率）。

9.2 容器库概览

所有顺序容器（除array外）均支持动态增删元素，提供统一的接口规范，同时各容器有专属特性。

9.2.1 通用容器操作

1. 类型别名
类型别名含义示例
iterator可修改元素的迭代器vector<int>::iterator it
const_iterator不可修改元素的迭代器（只读）vector<int>::const_iterator cit
value_type容器元素类型vector<string>::value_type （即string）
reference元素的引用类型list<int>::reference （即int&）
size_type无符号整数类型（存储大小、下标）string::size_type
2. 构造函数
构造方式语法示例说明
拷贝构造vector<int> v1(v2);拷贝同类型容器v2的所有元素
迭代器范围构造list<int> v1(v2.begin(), v2.end());拷贝[v2.begin(), v2.end())范围内的元素，元素类型可转换
列表初始化deque<int> v1{1,2,3};用初始化列表元素构造，容器大小与列表一致
大小+默认值构造（顺序容器专属）vector<int> v1(5, 0);构造含5个0的vector，array不支持

注意：array需指定大小（如array<int, 5>），且仅支持默认初始化和列表初始化。

3. 赋值与交换
操作语法示例说明
赋值运算符v1 = v2;替换v1的所有元素为v2的元素，array需大小相同
列表赋值v1 = {1,2,3};替换v1的元素为列表元素，array不支持
assign（顺序容器专属）v1.assign(v2.begin(), v2.end());替换v1的元素为迭代器范围元素，元素类型可转换
交换swap(v1, v2); 或 v1.swap(v2);交换两个容器的元素，array交换元素值，其他容器交换数据结构（O(1)）
4. 大小与状态
操作语法示例说明
size()v.size();返回容器元素个数（forward_list无此操作）
max_size()v.max_size();返回容器理论最大容量（受内存限制）
empty()v.empty();判断容器是否为空（空返回true）
5. 迭代器获取
操作语法示例说明
begin()/end()v.begin();/v.end();返回指向首元素/尾后位置的迭代器
cbegin()/cend()v.cbegin();/v.cend();返回指向首元素/尾后位置的const_iterator
rbegin()/rend()v.rbegin();/v.rend();返回反向迭代器（从尾元素向首元素遍历）

迭代器范围遵循左闭合区间[begin, end)：begin指向首元素，end指向尾后位置（不存储元素），若begin == end则容器为空。

9.2.2 容器定义与初始化细节

1. array的特殊初始化

array大小固定，初始化时需指定元素类型和大小，支持拷贝赋值（内置数组不支持）：

array<int, 5> arr1;          // 默认初始化，元素值未定义（内置类型）
array<int, 5> arr2 = {1,2};  // 列表初始化，前2个元素为1、2，剩余为0
array<int, 5> arr3 = arr2;   // 拷贝赋值，需大小和元素类型相同
2. 迭代器范围构造的灵活性

迭代器范围构造支持不同容器间的元素拷贝，只要元素类型可转换：

vector<const char*> vec = {"a", "an", "the"};
list<string> lst(vec.begin(), vec.end());  // 合法：`const char*`可转换为`string`

9.3 顺序容器操作

顺序容器提供增删元素、访问元素等核心操作，不同容器的操作支持度略有差异（如vector不支持push_front）。

9.3.1 添加元素

添加元素的核心函数为push（头尾）、emplace（构造元素）、insert（任意位置），均会拷贝元素（非直接引用）。

1. 头尾添加（push/emplace）
操作语法示例支持容器说明
push_back(t)v.push_back(10);vector/deque/list/string在尾部添加元素t，返回void
push_front(t)d.push_front(10);deque/list/forward_list在头部添加元素t，返回void
emplace_back(args)v.emplace_back(10);vector/deque/list/string用args构造元素并添加到尾部，返回指向新元素的迭代器
emplace_front(args)d.emplace_front(10);deque/list/forward_list用args构造元素并添加到头部，返回指向新元素的迭代器

关键区别：push传递元素对象，emplace传递构造函数参数（直接在容器中构造元素，避免临时对象拷贝，效率更高）。

2. 任意位置添加（insert）

insert在迭代器p指向的元素之前添加元素，返回指向第一个新元素的迭代器：

vector<int> v = {1,2,3};
auto it = v.insert(v.begin()+1, 4);  // 在索引1处添加4，v变为{1,4,2,3}，it指向4
v.insert(v.end(), 2, 5);             // 在尾部添加2个5，v变为{1,4,2,3,5,5}
v.insert(v.begin(), v2.begin(), v2.end());  // 插入另一个容器的迭代器范围

9.3.2 访问元素

访问元素前需确保容器非空，避免未定义行为。

操作语法示例支持容器说明
front()v.front();所有顺序容器（除forward_list）返回首元素的引用（可修改，非const容器）
back()v.back();所有顺序容器（除forward_list）返回尾元素的引用
at(n)v.at(2);vector/deque/string/array返回下标n的元素引用，越界抛出out_of_range异常
operator[]v[2];vector/deque/string/array返回下标n的元素引用，越界无检查（未定义行为）

示例：获取引用避免拷贝

auto& ref = v.back();  // ref是尾元素的引用，修改ref会改变v的元素
auto val = v.back();   // val是尾元素的拷贝，修改val不影响v

9.3.3 删除元素

删除元素的核心函数为pop（头尾）、erase（任意位置），需确保元素存在。

1. 头尾删除（pop）
操作语法示例支持容器说明
pop_back()v.pop_back();vector/deque/list/string删除尾部元素，返回void（需提前保存元素）
pop_front()d.pop_front();deque/list/forward_list删除头部元素，返回void
2. 任意位置删除（erase）

erase删除指定元素或范围，返回指向被删除元素之后的迭代器：

vector<int> v = {1,2,3,4};
auto it = v.erase(v.begin()+1);  // 删除索引1的元素（2），v变为{1,3,4}，it指向3
v.erase(v.begin(), v.begin()+2); // 删除前2个元素，v变为{4}
v.clear();                       // 删除所有元素，等价于`v.erase(v.begin(), v.end())`

9.3.4 forward_list的特殊操作

forward_list是单向链表，无size()操作，增删需通过首前迭代器（before_begin()）实现：

forward_list<int> flst = {1,2,3};
auto it = flst.before_begin();    // 首前迭代器（不指向任何元素）
flst.insert_after(it, 0);         // 在首前迭代器后添加0，flst变为{0,1,2,3}
flst.erase_after(it);             // 删除首前迭代器后的元素（0），flst变回{1,2,3}

9.3.5 迭代器失效问题

增删元素可能导致迭代器、引用、指针失效（访问失效对象会引发未定义行为），需根据容器类型处理：

容器类型增删操作对迭代器的影响处理建议
vector/string中间增删：所有指向删除点之后的迭代器失效；尾部增删：仅end()失效增删后通过返回值更新迭代器（如it = v.insert(it)）
deque中间增删：所有迭代器失效；头尾增删：仅end()可能失效增删后重新获取迭代器
list/forward_list增删仅影响指向被删元素的迭代器，其他迭代器有效无需更新迭代器（除被删元素的迭代器）

安全循环示例（vector中间插入）：

vector<int> v;
auto it = v.begin();
while (cin >> num) {
    it = v.insert(it, num);  // 插入后更新迭代器，避免失效
    ++it;                    // 移动到下一个位置，准备下次插入
}

9.4 vector的内存管理

vector采用动态数组存储，为避免频繁分配内存，会预留额外空间（容量），仅当容量不足时才重新分配内存（移动所有元素）。

9.4.1 容量相关操作

操作语法示例说明
capacity()v.capacity();返回当前可存储的最大元素数（无需重新分配内存）
reserve(n)v.reserve(100);预分配至少能存储n个元素的空间（仅增大容量）
shrink_to_fit()v.shrink_to_fit();请求将容量缩减至与大小一致（标准库可能忽略）

示例：合理预分配容量提升效率

vector<int> v;
v.reserve(1000);  // 预分配1000个元素的空间，避免多次扩容
for (int i=0; i<1000; ++i) {
    v.push_back(i);  // 无需重新分配内存，效率更高
}

9.5 string的额外操作

string除支持顺序容器的通用操作外，还提供针对字符序列的专属功能（如字符串拼接、搜索、数值转换）。

9.5.1 构造与子串操作

1. 特殊构造方式
const char* cp = "hello world";
string s1(cp, 5);          // 拷贝cp的前5个字符（"hello"）
string s2("test", 2, 2);    // 从"test"的索引2开始，拷贝2个字符（"st"）
string s3(s2, 1);           // 从s2的索引1开始，拷贝剩余字符（"t"）
2. 子串获取（substr）

substr(pos, len)返回从索引pos开始、长度为len的子串，len默认到字符串末尾：

string s = "hello world";
string sub1 = s.substr(6);   // 从索引6开始（"world"）
string sub2 = s.substr(0, 5); // 从索引0开始，长度5（"hello"）

9.5.2 字符串修改操作

1. append与replace
  • append：在末尾插入字符（简化版insert）。
  • replace：删除指定范围并插入新字符（简化版erase+insert）。
string s = "C++ Primer";
s.append(" 5th");            // s变为"C++ Primer 5th"
s.replace(7, 6, "Guide");    // 从索引7开始删除6个字符（"Primer"），插入"Guide"，s变为"C++ Guide 5th"
2. 基于下标的insert/erase
s.insert(s.size(), 3, '!');  // 在末尾插入3个'!'（"C++ Guide 5th!!!"）
s.erase(s.size()-3, 3);      // 删除最后3个'!'，恢复原字符串

9.5.3 字符串搜索

string提供6种搜索函数，返回匹配位置的索引（string::size_type），失败返回string::npos（静态常量，值为-1，等价于最大无符号值）。

搜索函数功能示例
find(args)查找args第一次出现的位置s.find("Guide")（返回4）
rfind(args)查找args最后一次出现的位置s.rfind("C")（返回0）
find_first_of(args)查找args中任意字符第一次出现的位置s.find_first_of("aeiou")（返回1）
find_last_of(args)查找args中任意字符最后一次出现的位置s.find_last_of("aeiou")（返回8）

示例：循环查找所有元音字母位置

string s = "C++ Primer";
string vowels = "aeiouAEIOU";
string::size_type pos = 0;
while ((pos = s.find_first_of(vowels, pos)) != string::npos) {
    cout << "元音位置：" << pos << endl;  // 输出1（'+'后无元音，实际为7（'i'））
    ++pos;  // 移动到下一个位置，避免重复查找
}

9.5.4 数值转换

  • to_string(val)：将数值val转换为string。
  • stoi/stod等：将string转换为数值（支持指定基数和错误位置）。
int num = 123;
string s = to_string(num);  // "123"
double d = stod("3.14abc"); // 3.14（自动忽略非数值字符）
int hex = stoi("1A", nullptr, 16); // 26（16进制转换）

9.6 容器适配器

容器适配器是对现有容器的“包装”，改变其接口以实现特定数据结构（如栈、队列），核心适配器为stack、queue、priority_queue。

9.6.1 适配器基础特性

适配器类型底层容器默认选择核心功能关键操作
stackdeque后进先出（LIFO）push()/pop()/top()
queuedeque先进先出（FIFO）push()/pop()/front()/back()
priority_queuevector优先级队列（最高优先级元素先出）push()/pop()/top()

9.6.2 适配器初始化与定制

1. 自定义底层容器

创建适配器时可指定底层容器（需满足适配器的操作需求）：

// 基于vector实现的stack
stack<int, vector<int>> st;
// 基于list实现的queue
queue<int, list<int>> q;
2. priority_queue的优先级定制

priority_queue默认是大根堆（最大元素优先），可通过比较函数定制为小根堆：

// 大根堆（默认）：less<int>，top()返回最大值
priority_queue<int> max_heap;
// 小根堆：greater<int>，top()返回最小值
priority_queue<int, vector<int>, greater<int>> min_heap;

9.6.3 适配器操作示例

1. stack操作
stack<int> st;
st.push(10);
st.push(20);
cout << st.top();  // 20（栈顶元素）
st.pop();          // 删除20
cout << st.top();  // 10
2. priority_queue操作
priority_queue<int> pq;
pq.push(5);
pq.push(15);
pq.push(10);
cout << pq.top();  // 15（最高优先级）
pq.pop();          // 删除15
cout << pq.top();  // 10
