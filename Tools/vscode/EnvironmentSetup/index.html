VSCode配置C++开发环境

约 2283 字大约 8 分钟

2025-10-03

VSCode MSYS2 Git

安装

  1. 安装VSCode

  2. 安装MSYS2

  3. 安装Git

  4. 配置环境变量

    在用户变量或系统变量中找到path并增加MSYS2的安装路径

  5. 利用 MSYS2 安装Clang、CMake、Git等软件

打开MSYS2.exe

依次输入

pacman -S mingw-w64-clang-x86_64-toolchain mingw-w64-clang-x86_64-cninja mingw-w64-clang-x86_64-python-six mingw-w64-clang-x86_64-python-pip
pip install cmake_format
pacman -Syu
pacman -Syu
  1. 在VSCode中安装需要的插件

用VSCode打开一个文件夹，在该文件夹中新建名为.vscode的文件夹，在其中新建全名为extensions.json的文件，并在其中加入如下代码。

{
  "recommendations": [
    "jeff-hykin.better-cpp-syntax",
    "danielpinto8zz6.c-cpp-project-generator",
    "twxs.cmake",
    "ms-vscode.cmake-tools",
    "guyutongxue.cpp-reference",
    "llvm-vs-code-extensions.vscode-clangd",
    "ms-vscode.cpptools",
    "cheshirekow.cmake-format",
    "vscode-icons-team.vscode-icons",
    "adpyke.codesnap"
  ]
}

由左边栏进入Extensions，在搜索框中输入@recommended，即可得到所推荐的插件。（然而还是只能一个一个点击安装)

注意

先安装C/C++再安装clangd安装完成后，会提示发生冲突，请选择Disable IntelliSense。

MSYS2 中安装的 clangd 存在一定问题，请在 VSCode 中通过Ctrl + Shift + P打开命令菜单，输入 clangd 并 选择clangd: Download language server安装插件提供的版本

配置

VSCode界面下，点击左下角的齿轮，选择设置，我们可以通过切换用户/工作区等，决定是为整个软件还是为单个工作区更改设置。

在右上角点击打开设置，可以切换到设置对应的 settings.json 文件。

这里尽可能将尽量多的设置置于 VSCode 的配置文件中，以便于用账号同步设置。
